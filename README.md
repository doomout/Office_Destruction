# Office Rampage — 사무실 파괴

직원들과 싸우고 사무집기를 부수는 **3D 3인칭 액션 게임**입니다. 대표에게 도전하는 **스토리 모드**와 장비를 주우며 오래 버티는 **무한 파괴 모드**를 제공합니다.

이 문서는 **2026-11-18 현재 구현된 기능**을 기준으로 합니다. 세부 변경 이력은 [업데이트 기록](OfficeRampage_Update.md)에 누적합니다.

## 실행하기

1. Unity Hub에서 프로젝트를 **Unity 6000.5.1f1**로 엽니다.
2. `Assets/OfficeRampage/Scenes/OfficeRampage.unity`를 엽니다. 메뉴의 **Tools → Office Rampage → Open Game Scene**으로도 열 수 있습니다.
3. Play를 누르고 Game 창을 클릭합니다.
4. 첫 메뉴에서 **스토리 모드** 또는 **무한 파괴 → 생존 시작**을 선택합니다.

렌더링은 **URP 17.5.0**, 입력은 **Input System 1.19.0**을 사용합니다. Active Input Handling은 **Both**입니다. 게임 조작은 Input System, 한글 이름 편집은 TextField/IME를 사용합니다. 기존 Unity 버전과 패키지 설정을 유지하세요.

## 두 모드의 차이

| 구분 | 스토리 모드 | 무한 파괴 모드 |
| --- | --- | --- |
| 목표 | 4개 층을 돌파하고 대표 처치 | 끝없이 생성되는 적을 상대하며 생존 |
| 시작 무기 | 야구빠따 | 광선검 |
| 무기 교체 | 숫자키 1~8, 비밀 무기는 획득 후 사용 | 바닥 무기 근처에서 E로 줍기만 가능 |
| 탄약 소진 | 해당 총기를 사용할 수 없음 | 기본 광선검으로 자동 복귀 |
| 진행 조건 | 1~3층 직원 전원 처치, 4층 호위 순서 진행 | 층 이동·보스 처치 조건 없음 |
| 배경 | Unity에서 편집하는 층별 프리팹 | 실행 시 생성하는 별도 광장 |
| 가구 | 선택적으로 파괴하는 집기·함정 | 부수면 안전한 위치부터 재생성 |
| 시간 | 제한 시간 없음 | 제한 없이 생존 시간을 기록 |
| 종료 | 패배 또는 대표 엔딩 | 체력 0이면 결과와 재도전 메뉴 |

## 조작

| 입력 | 동작 |
| --- | --- |
| WASD / 마우스 | 이동 / 시점·조준 |
| Space | 점프 |
| 왼쪽 Shift + 이동 | 달리기, 최대 10초 |
| 왼쪽 클릭 | 공격 / 더미 투척 / 소환·탑승 무기 사용 |
| 오른쪽 클릭 | 더미 조준·취소 / 헐크버스터 탑승 중 대쉬(재사용 3초) |
| F | 준비된 콤보 스킬 사용 |
| 1~8 | 스토리 모드 무기 선택. 무한 모드에서는 교체 불가 |
| E | 무한 모드 바닥 장비·보급품 획득 |
| Esc | 일시정지·재개 |
| M | 전체 음소거 |

달리기 게이지는 초당 2초분씩 회복합니다. 완전히 소진하면 Shift를 놓고 최소 2초분을 회복해야 다시 달릴 수 있습니다. **R키로 재시작하는 기능은 없습니다.** 재시작은 결과 화면이나 첫 메뉴에서 선택합니다.

## 메뉴와 회사 설정

첫 메뉴는 **스토리 모드 / 무한 파괴 / 설정 / 스토리 / 끝내기**로 구성됩니다. ‘스토리’는 배경 설명이며, 실제 진행은 ‘스토리 모드’에서 시작합니다.

설정에서 음악·효과음 음량과 전체 음소거를 조절합니다. **설정 → 유닛 설정**에서는 직급별 인물의 **이름과 성별**을 변경합니다. 이름은 처음에 무작위로 지정되며 한글을 포함해 최대 24자입니다. 이름 편집창에서 적용한 뒤 유닛 설정에서 저장하면 다음 새 게임에 반영됩니다. 인원수는 변경할 수 없습니다.

설정 대상 직원은 총 **43명**입니다. 경비는 설정 명단에서 제외되지만, **대표층 보디가드 5명은 별도로 등장**합니다. 경비견과 비서는 이 명단에 포함되지 않습니다. 성별에 따른 기본 체력·피해·충돌 크기는 같으며 외형과 미인계 더미 반응이 다릅니다.

## 스토리 모드

### 시작 선택과 층 진행
| 층 | 공간 | 진행 |
| --- | --- | --- |
| 1층 | 가구 없는 로비 | 사원 10명, 각 체력 100 |
| 2층 | 책상·의자·복합기·수납장이 배치된 사무실 | 주임~부장 26명 |
| 3층 | 파티션을 제거한 임원 업무 공간 | 이사~부사장 6명 |
| 4층 | 경비견실 → 보디가드실 → 대표실·비서실 | 경비견 5마리 → 보디가드 5명 → 대표 |

**1~3층은 직원 100% 처치 시 엘리베이터가 열립니다.** 가구 파괴 비율은 문 조건에 포함하지 않습니다. 엘리베이터를 타면 다음 층으로 이동하고 이전 층은 제거됩니다. 시간 제한과 콤보 시간 보너스는 없습니다.

대표층은 경비견을 모두 처치하면 첫 구역의 벽과 문이 사라지고, 보디가드까지 모두 처치하면 둘째 구역의 벽과 문이 사라지면서 대표의 무적이 해제됩니다. 보디가드는 몽둥이 2명·권총 2명·장거리 샷건 1명입니다.

체력은 최대 100입니다. 층별 기본 회복 포션은 2개이며 각각 30을 회복합니다. 정수기 파괴는 체력 +5, 전자기기 파괴는 피해 5를 주는 함정으로 작동합니다. 가구를 파괴하지 않아도 진행할 수 있습니다.

### 기본 무기와 콤보

| 스토리 키 | 무기 | 기본 특징 |
| --- | --- | --- |
| 1 | 야구빠따 | 피해 40, 무제한. F: 10초 휠윈드 |
| 2 | 망치 | 피해 90, 무제한. F: 망치를 치켜들고 3초간 낙뢰, 사람 3초 기절 |
| 3 | 권총 | 200발, 피해 32. F: 10초 얼음탄, 피격 유닛 3초 동결 |
| 4 | 기관총 | 빠른 연사, 발당 피해 12, 무제한 탄약 |
| 5 | 미인계 더미 | 층당 3회. 오른쪽 클릭으로 궤적 조준, 왼쪽 클릭 투척. 10초 남성 직원 유인 |
| 6 | 화염 샷건 | 100발. 권총과 같은 단일 타격 + 5초간 초당 1 화상 피해 |
| 7 | 로켓런처 | 20발. 직진 화염 꼬리, 폭발 피해 120 / 반경 4.5m |
| 8 | BFG 18 / ??? | 대표전에서 순서대로 획득하는 일회용 비밀 무기 |

일반 공격으로 **가구를 파괴하거나 사람을 처치하면** 콤보가 쌓입니다. 4초 동안 이어 가지 못하면 초기화됩니다. 방망이·망치·권총의 일반 공격으로 3콤보 단위에 도달하면 해당 스킬이 준비되며, 10초 안에 해당 무기로 F를 눌러 사용합니다. 무한 모드 기본 광선검도 방망이와 같은 휠윈드를 사용합니다.

**휠윈드·낙뢰·얼음탄·지속 화상·소환 지원 등 스킬 피해로는 콤보를 재충전하지 않습니다.** 미인계 더미는 여성·대표·경비견에게 통하지 않습니다. 화상은 가구의 불꽃·연기와 사람의 당황하는 움직임으로 표현됩니다.

스토리의 권총·샷건·로켓 잔탄은 층 이동 시 유지됩니다. 새 게임과 **대표의 로봇 탑승 직후**에는 각각 200 / 100 / 20발을 보급합니다. 얼음탄도 권총 탄약을 소비합니다. 스토리 HUD는 무기 아이콘과 남은 수량을 표시합니다.

## 무한 파괴 모드

64m 광장에서 적을 처치하고 가구를 부수며 오래 버팁니다. **바닥 무기 19종 + 기본 광선검**을 사용할 수 있습니다. 층 이동이나 대표전은 없고, 생존 시간·처치 수·점수를 HUD와 결과 화면에 표시합니다.

### 장비와 보급

- **광선검으로 시작**합니다. 피해 40과 3콤보 F 휠윈드는 방망이와 같습니다. 탄약·일회용 사용량이 소진되면 광선검으로 자동 복귀합니다.
- 바닥 장비 **2.5m 이내에서 E**로 줍습니다. 무기는 즉시 교체되며 이전 장비를 보관하는 인벤토리는 없습니다. 숫자키 교체는 불가능합니다.
- 새 무기를 주우면 해당 탄약·횟수가 채워집니다. 기본 무기 수량은 위 표와 같습니다. 미인계 더미는 무한 모드에서 생성·획득하지 않으며 스토리 모드에만 남습니다.
- 갑옷은 내구도 +60, 최대 100입니다. 공격 피해의 70%를 남은 내구도만큼 흡수합니다. 회복 보급은 체력 +30입니다.
- 보라색 **피해 2배** 아이템은 20초간 적·가구에 주는 피해를 2배로 만듭니다. 다시 주우면 시간이 갱신되며 4배로 중첩되지 않습니다.
- 가구는 재생성됩니다. 무한 모드의 전자기기 폭발은 주변 적에게 피해를 줍니다.

### 5분마다 바뀌는 무한 모드 배경

- 처음에는 기존 광장으로 시작하고, 첫 전환은 **사막**, 이후에는 **무인도 ↔ 사막**으로 번갈아 바뀝니다. 사막에는 모래언덕·선인장·바위 지형, 무인도에는 바다·해변·야자수·움직이는 파도가 있습니다.
- 생존 시간 **5분·10분·15분…**마다 전환합니다. 일시정지와 위성 연출 중에는 생존 시간이 흐르지 않습니다.
- **BFG 18 발사, 헐크버스터 탑승 성공** 시 즉시 한 번 전환합니다. 전투기 폭격과 블랙홀도 지원 종료 시 한 번 전환합니다. **위성 호출기**는 우주 연출이 끝나고 전장으로 돌아왔을 때 전환하며, 기존의 빈 전장 3초와 재생성은 유지합니다. 단순 획득이나 탄약 없는 클릭은 전환하지 않습니다.
- 무기 사용으로 바뀌어도 다음 5분 주기는 밀리지 않습니다. 배경 전환 자체는 체력·갑옷·생존 시간·점수·킬 수·장비·적·가구를 초기화하지 않습니다. 무기의 기존 폭발/정리 효과는 그대로입니다.
- 이동 범위와 바닥·경계 충돌은 원래 64m 전장을 유지하며, 낮은 돌로 경계를 표시합니다. 바다와 먼 모래언덕은 배경입니다. 새 게임은 원래 광장으로 시작합니다. **스토리 모드에는 적용하지 않습니다.**

### 드론·전투기·블랙홀

| 무기 | 사용량 | 동작 |
| --- | --- | --- |
| 드론 조종기 | 1회 | 드론 3대가 10초 동안 플레이어 주변을 순회하며 약 1.25초마다 수류탄 투하. 적 주변의 무작위 지점을 폭격하며 폭발 반경6m/피해100. 배경은 바뀌지 않음 |
| 전투기 폭격 지원 | 1회 | 전투기 3대가 나란히 일직선으로 5초 동안 통과하며 폭격. 종료 시 남은 적·가구도 전멸하고 사막/무인도로 배경 전환 |
| 블랙홀 생성기 | 1회 | 전방에 5초간 블랙홀 소환. 적·가구·바닥 보급을 끌어들여 제거하고 종료 시 배경 전환. 플레이어와 장착 무기는 흡입하지 않음 |

- 세 무기는 초기 배치와 3초 무기 보급 목록에 포함됩니다. E로 줍고 왼쪽 클릭으로 사용합니다. 사용 후 기본 광선검으로 돌아가 계속 공격할 수 있습니다.
- 공중 지원 중에는 카메라를 넓히고, 끝나면 원래 시야로 돌아옵니다. 드론은 한 편대(3대)만 유지하며 재사용하면 10초로 갱신합니다. 이미 떨어지는 수류탄은 착탄할 때까지 남습니다. 지원 폭탄은 동시에 최대24개입니다.
- 전투기/블랙홀 진행 중에는 적·가구·보급의 새 생성을 잠시 멈춥니다. 종료 후 무기 보급은 약1초, 적·가구 확인은 약3초 뒤 재개합니다. 기존 물건의 자연 재생성 안전 조건은 유지합니다.
- 새 궁극기가 진행 중일 때 BFG/위성/헐크버스터/다른 새 궁극기를 중복 발동할 수 없습니다. 이때 탄약은 소비하지 않습니다. 일반 공격과 장비 줍기는 가능합니다.
- 지원 공격은 플레이어에게 피해를 주지 않고 콤보를 충전하지 않습니다. 일시정지 시 지원 시간도 멈추며, 사망/재시작/위성 정리 시 소환물을 정리합니다. 드론·전투기·블랙홀 아이콘과 남은 시간은 하단 HUD에 표시합니다.
- 구현: `Scripts/Endless/OfficeRampageGame.AirSupport.cs`, `OfficeRampageGame.BlackHole.cs`. 스토리 모드에는 추가하지 않습니다.

### 헐크버스터 타기

시작 지점 뒤쪽 중앙에 있는 **헐크버스터 조종기**를 E로 줍고 왼쪽 클릭하면 탑승합니다. 지옥문과 교통사고도 초기 장비에 포함됩니다.

| 탑승 조작·효과 | 내용 |
| --- | --- |
| 탑승 시간 | 20초. 일시정지하면 시간도 정지 |
| 왼쪽 클릭 | 빨강·초록 쌍검 동시 가로 베기: 피해 120, 범위 7m, 간격 0.75초 |
| 오른쪽 클릭 | 대쉬: 재사용 3초, 전방 최대 10.5m, 충돌 피해 120·기절 1.5초 |
| 방어 | 받는 피해 50% 감소 후 갑옷 흡수 적용 |
| 보급 | 체력·갑옷·피해 2배는 획득 가능. 다른 무기 교체는 탑승 종료 후 가능 |
| 종료 | 로봇 제거, 원래 캐릭터 크기·카메라로 복구하고 광선검 장착 |

탑승 공격은 콤보를 충전하지 않습니다. 로봇 외형·큰 충돌체·다리 움직임·조종석 인물·전용 카메라가 적용됩니다.

### 피해 2배 획득 확인

- 획득 순간 발밑에서 흰 고리가 퍼지고 효과음이 납니다. 효과가 유지되는 동안 보라색 바닥 고리와 회전하는 빛이 플레이어를 따라다닙니다.
- 무기창 위에 전용 **×2 / 남은 초 / 게이지**가 표시됩니다. 마지막 3초에는 주황·보라색으로 색이 바뀌고, 만료되면 표시와 캐릭터 효과가 함께 사라집니다. 화면 중앙의 긴 메시지는 추가하지 않습니다.
- 재획득은 20초로 갱신하며 고리를 다시 보여줍니다. 4배로 중첩되거나 효과가 여러 개 쌓이지 않습니다. 무기를 바꿔도 유지되며 헐크버스터 탑승 시 캐릭터 효과도 커집니다.
- 기존 피해 2배·20초 규칙과 일시정지 동작은 유지합니다. 사망/재시작 시 효과를 정리합니다. 구현은 `Scripts/Endless/OfficeRampageGame.DoubleDamageFeedback.cs`입니다.

### 전투 HUD: 아이콘과 숫자

- 스킬 준비/발동 문구는 하단 아이콘으로 표시합니다. 소용돌이=휠윈드, 번개=토르의 망치, 눈꽃=얼음탄이며 숫자는 남은 초입니다. 청록색 `F`는 현재 무기로 발동 가능, 주황색은 사용 중입니다. 스토리에서 다른 무기의 준비 상태는 작은 무기 번호로 표시합니다.
- 스토리의 하트는 더미의 남은 횟수 또는 유인 시간, 물방울 `50%`는 기름 감속입니다. 무한 모드의 피해 2배·악마·자동차·로봇 지원도 아이콘과 남은 초로 표시합니다.
- 달리기는 사람 아이콘·남은 초·게이지·`Shift`로 표시합니다. 회복/탄약/획득/층 이동 알림은 오른쪽 가장자리의 작은 아이콘으로 표시합니다. 장비 근처의 `E` 표시는 줍기입니다.
- 조준 방향 적의 기절/빙결은 우측 번개/눈꽃과 남은 초로 표시합니다. 머리 위 이름·체력은 크기를 줄여 유지합니다.
- 화면 중앙에 뜨던 긴 스킬/버프/투척 설명과 전투 연출 안내 문구는 표시하지 않습니다. 조작 설명은 메뉴와 이 문서에서 확인할 수 있습니다. 도입부 대사·엔딩·메뉴·랭킹 화면은 유지합니다.
- HUD 도형·크기·배치는 `Scripts/UI/OfficeRampageGame.CompactHUD.cs`에서 수정합니다. 새 외부 아이콘 에셋은 추가하지 않았습니다.

### 생성 제한과 기록

- 적은 시작 5초 후부터 계속 증원됩니다. 생존에 따라 생성 간격과 체력이 강화되며 **한 번에 2명씩 생성하며 동시 적 상한은 80명**입니다.
- **무기는 3초마다 별도로 등장**합니다. 플레이어 주변 6~12m의 빈 위치를 우선 찾고, 무기 목록을 섞어 한 순환 안에서 반복을 줄입니다. 번개 스테이플러·레이저 프린터·용암 커피포트도 초기 배치에 포함됩니다. BFG/위성 호출기는 30초 이후 보급 목록에서 선택됩니다.
- 회복/갑옷 보급은 별도로 8초마다 등장하며 14% 확률로 피해 2배 보급이 대신 나옵니다. 최대 18개를 유지하고 회복 보급이 무기 8개 이하를 밀어내지 않도록 보호합니다. 이미 줍기 범위 안에 있는 장비도 교체 대상에서 제외합니다.
- 가구 36개는 10초마다 재생성 가능 여부를 확인합니다. 플레이어 근처나 다른 충돌체가 있는 자리는 피합니다.
- 차량은 동시에 최대 8대, 각 3초 수명이며 지원 10초가 끝나면 정리됩니다. 일반 효과·파편에도 개수 제한이 있습니다.
- 개인 **최고 생존 시간과 최고 점수**는 로컬 PlayerPrefs에 저장합니다. 최고 생존 시간은 HUD에 표시됩니다.

**로컬 Top 10:** 게임 종료 후 이름(한글 가능, 최대 24자)을 입력하고 **기록 등록**을 누릅니다. 종합점수는 **게임 점수 + 생존 초 × 10 + 처치 수 × 100**입니다. 한 판의 기록을 기준으로 정렬하며, 같은 이름으로 여러 판을 등록할 수 있습니다. 동점이면 생존 시간 → 처치 수 → 게임 점수 → 먼저 등록한 기록 순입니다. 등록을 건너뛰고 재도전하거나 메뉴로 돌아갈 수도 있습니다. 첫 메뉴의 **무한 파괴 → Top 10 랭킹**에서 다시 확인하세요. 기록은 이 PC에 저장되며 온라인 공유나 여러 판의 합산 순위는 아닙니다.

보급 수치와 무기별 세부 처리는 [무한 파괴 안내](Docs/ENDLESS_MODE.md)를 참고하세요.

### 가로 베기 모션

광선검과 야구빠따의 일반 공격은 일정한 높이에서 좌우로 휘두른 뒤 정면 준비 자세로 돌아갑니다. 플레이어 헐크버스터의 검도 수평으로 베며 가로 호 궤적을 표시합니다. 방망이는 스토리와 무한 모드 모두 적용합니다. 피해량·사거리·공격 간격·콤보 판정은 유지합니다. 망치의 낙뢰 준비 자세와 더미 투척은 기존 동작을 사용합니다. 공통 회전은 `Scripts/Player/OfficeRampageGame.HorizontalSwing.cs`에서 조정합니다.


### 헐크버스터 쌍검과 대쉬

왼손 초록색·오른손 빨간색 광선검을 동시에 가로로 휘두릅니다. 쌍검은 한 번의 공격 판정으로 피해 120을 줍니다. 오른쪽 클릭은 누를 때마다 대쉬를 시도하며, 3초 후 다시 사용할 수 있습니다. 0.35초 동안 전방으로 빠르게 이동하고 벽이나 장애물에 부딪히면 멈춥니다. 닿은 적·가구에는 대쉬당 한 번씩 피해 120을 주며 적은 1.5초 기절합니다. 대쉬 피해도 스킬 피해이므로 콤보가 쌓이지 않습니다. 작은 달리기 아이콘과 숫자가 대기시간을 표시합니다. 기존 오른쪽 광선 발사는 대쉬로 교체했습니다.


### 무한 모드 상단 정보

기존 왼쪽 위 여러 줄 패널을 화면 맨 위의 얇은 한 줄로 통합했습니다. 생존 시간·처치 수·점수·콤보·현재 적 수/상한·최고 생존 기록을 표시합니다. 숫자가 길어지면 글자 크기를 자동 조절하며, 적 체력 아이콘과 겹치지 않도록 오른쪽 공간을 확보했습니다.
