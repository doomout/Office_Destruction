# Office Rampage — 사무실 파괴

직원들과 싸우고 사무집기를 부수며 대표에게 도전하는 3인칭 액션 게임입니다. 사무실은 저장된 고정 배치를 읽어 생성하고, 인간 캐릭터는 무료 Kenney 모델을 사용합니다. 무기·가구·효과는 현재 코드 생성 방식입니다. 이 문서는 **2026-11-14 현재 구현**을 기준으로 합니다.

## 실행

1. Unity Hub에서 이 프로젝트를 **Unity 6000.5.1f1**로 엽니다.
2. `Assets/OfficeRampage/Scenes/OfficeRampage.unity`를 열거나 **Tools → Office Rampage → Open Game Scene**을 선택합니다.
3. Play를 누른 뒤 Game 창을 클릭합니다.
4. 첫 메뉴 → 사무실 파괴 → 도입 이야기에서 선택합니다.

URP 17.5.0, Input System 1.19.0을 사용합니다. 입력 설정은 **Both**이며, 게임 조작은 Input System, 한글 이름 입력은 기본 TextField/IME를 사용합니다.

## 조작

| 입력 | 동작 |
| --- | --- |
| WASD / 마우스 | 이동 / 시점 |
| Space | 점프 |
| 왼쪽 Shift + 이동 | 최대 10초 달리기 |
| 왼쪽 클릭 | 공격, 더미 조준 중 투척 |
| 오른쪽 클릭 | 더미 조준/취소 및 점선 궤적 |
| 1~8 | 무기 선택 (8은 BFG 획득 후) |
| F | 현재 무기의 준비된 콤보 스킬 |
| Esc | 일시정지/재개 |
| M | 전체 음소거 |
| R | 1층부터 즉시 재시작 |

달리기 게이지는 초당 2초분씩 회복합니다. 완전히 소진하면 Shift를 놓고 최소 2초분을 회복한 뒤 다시 사용합니다.

## 시작 이야기와 메뉴

- **사무실 파괴하기:** 1층에서 정상 게임 시작.
- **닥치고 출근하기:** 전체 직원 43명이 3겹으로 포위해 12초 이상 집중 공격합니다. 쓰러진 뒤 **업무 스트레스로 사망**과 첫 메뉴/다시 선택하기 버튼이 표시됩니다.
- **설정:** 음악·효과음·음소거·난이도·인물별 이름/성별 설정.
- **스토리:** 배경 설명. **무한파괴:** 현재 준비 중인 안내 화면입니다.

## 진행과 난이도

| 난이도 | 시작 제한시간 |
| --- | --- |
| 개빡침(어려움) | 1분 |
| 빡침(중간) | 2분 |
| 스트레스(쉬움) | 3분 |

일반 4개 층을 거쳐 5층 대표 사무실로 갑니다. 일반층은 **물건 60% 파괴 + 적 60% 처치**를 모두 달성하면 엘리베이터 문이 1.6초에 걸쳐 열립니다. 안으로 들어가면 다음 층으로 이동하며 이전 층 오브젝트를 제거합니다. 돌아갈 수 없습니다.

일반 물건을 파괴한 뒤 4초 안에 다음 물건을 부수면 콤보가 이어지고 **3·6·9…콤보마다 5초**를 더 받습니다. 인간 처치는 파괴 콤보에 포함하지 않습니다. 일반층마다 시간이 새로 지급되지는 않습니다. 엘리베이터 이동과 대표층(경비견 포함)에서는 시간이 줄지 않습니다.

시작/최대 체력은 100입니다. 각 층 포션은 2개로 30씩 회복하며 최대 체력일 때는 소비하지 않습니다. 정수기 파괴는 +5, 전자기기 파괴는 거리와 무관하게 -5입니다. 기름 위에서는 이동속도가 절반입니다. 체력 0 또는 일반층 제한시간 종료 시 패배합니다.

## 무기와 스킬

| 키 | 무기 | 특징 |
| --- | --- | --- |
| 1 | 야구빠따 | 근접 피해 40, F 스킬은 10초 휠윈드 |
| 2 | 망치 | 근접 피해 90, F 스킬은 10배 망치와 직선 번개 1회 |
| 3 | 권총 | 피해 32/사거리 24, F 스킬은 10초 얼음탄·피격 유닛 3초 동결 |
| 4 | 기관총 | 발당 피해 12, 빠른 연사 |
| 5 | 미인계 더미 | 층당 2회, 착지 후 10초 남성 직원 유인. 여성·대표·경비견 면역 |
| 6 | 불 속성 샷건 | 권총과 같은 단일 타격 + 5초간 초당 1 화상 피해 |
| 7 | 로켓런처 | 직진 화염 꼬리, 폭발 피해 120/반경 4.5 |
| 8 | BFG 18 | 대표전에서 획득하는 1회용 핵폭발 무기 |

방망이·망치·권총은 해당 일반 공격으로 3콤보 단위에 도달하면 스킬이 준비되며, 10초 안에 해당 무기를 들고 F를 누릅니다. 발동 시 콤보를 소비합니다. 망치 번개는 피해 180/길이 30/폭 3이며 확대는 1.2초 후 복귀합니다. 얼음탄 재명중은 동결을 3초로 갱신합니다.

**휠윈드·번개·얼음탄·지속 화상은 콤보, 추가 시간, 스킬 재충전을 만들지 않습니다.** 기본 점수와 문 개방 진행은 반영합니다. 일반 무기는 탄약 무제한, 더미/BFG는 횟수 제한입니다.

## 우리 회사 인물 설정

설정 → 유닛 설정에서 직급을 고르고 각 인물의 이름과 성별만 바꿉니다. 인원은 고정이며 처음 이름은 무작위입니다. 한글 이름은 최대 24자, 편집창에서 적용 후 유닛 설정에서 저장합니다. 저장 결과는 다음 새 게임부터 반영됩니다.

| 층 | 구성 | 엘리베이터 처치 목표 |
| --- | --- | --- |
| 1 | 사원 10, 주임 8 | 11/18 |
| 2 | 대리 6, 과장 5 | 7/11 |
| 3 | 차장 4, 부장 3 | 5/7 |
| 4 | 이사 2, 상무 2, 전무 1, 부사장 1 | 4/6 |
| 5 | 대표 1, 별도 경비견 5 | 경비견 전원 처치 후 대표 활성화 |

인간 총 43명입니다. 경비는 현재 생성/설정에서 제외되어 있지만 코드는 보존했습니다. 성별에 따른 체력·피해·충돌 크기는 같고 외형과 더미 반응이 다릅니다.

## 대표전과 엔딩

대표는 몽둥이·음파·서류를 사용하고 체력이 절반 이하가 되면 분노해 속도/범위가 50% 증가합니다. 20% 이하에서 비서가 BFG 18을 전달합니다. 핵폭발의 버섯구름 후 사무실보다 넓은 경계가 있는 사막으로 전환되고, 대표가 돈 갑옷을 입습니다. 2페이즈 현재/최대 체력은 700입니다.

대표 처치 후 쓰러지는 동작과 무작위 마지막 대사, 확인/재게임 버튼이 나옵니다. 확인은 첫 메뉴, 재게임은 1층 즉시 시작입니다. BFG 폭발·사막 전환 자막은 제거했고 비서 전달 안내는 유지합니다.

## 유지보수와 검사

폴더만 분리했으며 기존 스크립트/씬의 `.meta` GUID를 보존합니다. `OfficeRampageGame.*`는 여러 파일에 나눈 하나의 partial 클래스이므로 서로 다른 폴더에서도 함께 컴파일됩니다. Unity 버전·패키지·입력 설정을 유지하고, 실제 검사 결과는 [업데이트 기록](OfficeRampage_Update.md)에 남깁니다.

한글 입력은 사용자 플레이에서 정상 동작이 확인되었습니다. 자동 검사는 게임 규칙과 진행 흐름을 확인하며, 새 그래픽/음악의 품질·손맛·모든 해상도는 직접 플레이해서 확인해야 합니다.


## 고정 사무실과 새 캐릭터

층별 크기·가구 종류/위치/방향·기름·적 시작 위치·포션 위치는 `Resources/OfficeLayouts/floor1.json`~`floor5.json`에 고정 저장합니다. 새 게임마다 같은 배치이며, 적은 시작 후 기존 AI에 따라 움직입니다. 설정의 최초 이름 생성, 전투 동작 타이밍, 파편 효과 등은 별개입니다.

인간 캐릭터는 [Kenney Mini Characters 2.0](https://kenney.nl/assets/mini-characters)의 남성 6종/여성 6종을 사용합니다. CC0 라이선스 원문과 출처를 `Art/KenneyMiniCharacters`에 보관했습니다. 주인공·직원·대표·비서·더미·출근 군중에 적용되며, 개방형 사무실 가구와 경비견 모델은 기존 방식입니다. 걷기/달리기/공격 애니메이션을 연결하고 기존 충돌 크기·체력·무기·스킬 규칙은 유지합니다.

모델 목록은 `Resources/OfficeCharacters/Catalog.asset`에서 바꿀 수 있습니다. 자세한 적용 조건과 고정 배치 편집 방법은 [가이드](Docs/ASSET_GUIDE.md)를 참고하세요.
