# Office Rampage — 사무실 파괴

사무집기를 부수고 경비와 직원들을 상대하며 대표에게 도전하는 3인칭 액션 게임입니다.
사무실과 캐릭터는 실행 시 생성되며, 무기별 공격·파괴 콤보·유인용 더미·대표의 2페이즈 전투가 구현되어 있습니다.

게임 내 안내·상태·버튼·문 표지는 한글로 표시합니다. 키보드 키 표기는 실제 입력 키를 따릅니다.

이 문서는 **2026-11-13 현재 코드**를 기준으로 합니다. 변경 과정은 [OfficeRampage_Update.md](OfficeRampage_Update.md)에 누적합니다.

## 실행 환경

- Unity Editor: **6000.5.1f1**
- 렌더 파이프라인: **URP 17.5.0**
- 입력 시스템: **Input System 1.19.0**
- 기준 개발 환경: Windows


## 우리 회사 유닛 설정

**첫 메뉴 → 설정 → 유닛 설정**에서 왼쪽 직급을 고르고 오른쪽 목록의 **각 인물 이름과 성별만** 수정합니다. 이름을 누르면 별도 이름 편집창이 열립니다. 이름은 처음에 무작위로 채워지며, 저장한 이름과 성별은 다음 실행에도 유지됩니다. 긴 목록은 마우스 휠로 스크롤합니다.

| 직급 | 고정 인원 | 배치 |
| --- | ---: | --- |
| 사원 | 10 | 첫 사무실 |
| 주임 | 8 | 첫 사무실 |
| 대리 | 6 | 두 번째 사무실 |
| 과장 | 5 | 두 번째 사무실 |
| 차장 | 4 | 세 번째 사무실 |
| 부장 | 3 | 세 번째 사무실 |
| 이사 | 2 | 네 번째 사무실 |
| 상무 | 2 | 네 번째 사무실 |
| 전무 | 1 | 네 번째 사무실 |
| 부사장 | 1 | 네 번째 사무실 |
| 대표 | 1 | 대표 사무실 |

총 **43명**으로 인원 추가·삭제·변경 기능은 없습니다. 대표 사무실의 **경비견 5마리**는 별도 유지합니다. 경비는 이번 구성에서 생성하지 않고 설정에도 표시하지 않지만, 코드와 모델 생성 기능은 이후 재사용을 위해 보존합니다.

- **이름:** 이름 버튼을 눌러 편집창에서 한/영 키로 전환해 입력합니다. 한글 조합을 마친 뒤 **적용**, 유닛 설정에서 **저장**을 누릅니다. 인물별 최대 24자. 비어 있는 이름은 저장할 수 없습니다. 같은 직급에서도 각각 다른 이름을 지정할 수 있습니다.
- **성별:** 인물별 남/여 선택. 이름표와 머리·정장 실루엣·스카프와 이름표 색에 반영하며 성별에 따른 능력치 차이는 없습니다.
- **저장:** 다음 새 게임 또는 R 재시작부터 적용합니다. 진행 중인 게임의 이름·성별은 바꾸지 않습니다.
- **취소:** 저장하지 않은 변경을 버립니다.

이전 직급별 공통 이름 설정이 있으면 해당 직급 첫 인물에게 이름·성별을 옮기고, 나머지는 무작위 이름으로 채웁니다. 예전 인원 설정은 사용하지 않습니다. 새 부사장은 체력 220에 음파/A4 교대 공격을 사용하며 최종 보스가 아닙니다.

출구의 60% 처치 목표는 현재 고정 배치에 맞춰 계산합니다. 첫 사무실 **11/18명**, 두 번째 **7/11명**, 세 번째 **5/7명**, 네 번째 **4/6명** 처치와 각 방의 물건 60% 파괴가 필요합니다.

## 달리기와 캐릭터 표시

- 왼쪽 시프트와 이동 키를 함께 누르면 **최대 10초** 동안 달립니다. 왼쪽 아래 게이지에서 남은 시간을 확인할 수 있습니다.
- 게이지가 소진되면 걷기로 전환합니다. 달리지 않는 동안 초당 2초분씩 회복하여 완전 회복에는 최대 5초가 걸립니다. 소진 후에는 시프트를 놓고 최소 2초분을 회복한 뒤 다시 누르세요.
- 걷기는 기본 다리 움직임, 달리기는 더 빠르고 큰 다리 움직임과 몸 주변 바람 궤적으로 구분합니다. 일시정지와 전투 연출에서는 게이지도 멈춥니다.
- 남성 모델은 짧은 머리·넓은 어깨·바지 정장, 여성 모델은 긴 머리·포니테일·치마 정장·스카프로 구분합니다. 이름표 색은 보조 표시이며, 성별로 체력/피해/충돌 크기가 달라지지 않습니다.

| 2 | 망치 | 느린 근접 공격, 기본 피해 90 |

## 사무실 진행과 생존 규칙

- 플레이어 시작 체력과 최대 체력은 **100**입니다.
- 일반 사무실 출구는 **물건 60% 이상 파괴 + 인간 60% 이상 처치**를 모두 달성해야 열립니다. 필요한 개수는 올림합니다.
- 조건을 달성하면 출구 표시가 청록색으로 바뀌고, **1.6초간 좌우로 열리는 엘리베이터 문**이 완전히 열린 뒤 안으로 들어가면 다음 층으로 이동합니다. 탑승 중 시간은 멈추며 지난 층의 가구·적·아이템·투사체·효과와 목록을 정리합니다.
- 물건을 부순 뒤 **4초 안에** 다음 물건을 부수면 파괴 콤보가 이어집니다. 인간 처치는 현재 파괴 콤보에 포함하지 않습니다.
- **3·6·9…콤보마다 +5초**가 추가됩니다. 일반 사무실마다 제한시간을 새로 지급하는 구조는 아닙니다.
- **대표 사무실에 들어간 뒤에는 제한시간이 줄어들지 않습니다.** 경비견 전투부터 대표 2페이즈까지 포함합니다.
- 체력이 0이면 패배합니다. 시간 제한이 적용되는 일반 사무실에서 시간이 0이 되어도 패배합니다.

### 회복과 환경 위험

- 각 사무실에 회복 포션이 **2개씩** 무작위 배치됩니다. 가까이 가면 최대 체력 범위에서 **30 회복**합니다.
- 체력이 가득 차면 포션을 소비하지 않습니다. 사막 전환 후에도 포션이 새로 생성됩니다.
- 정수기를 부수면 체력이 **5 회복**됩니다.
- 컴퓨터가 있는 책상이나 복사기 같은 전자기기를 파괴하면 플레이어 체력이 **5 감소**합니다. 원거리 파괴라도 적용됩니다.
- 기름 위에서는 이동속도가 절반으로 줄어듭니다.
- 내부 칸막이를 없앤 개방형 사무실이지만 가구와 외곽 경계의 충돌은 유지합니다.

- 이름 편집은 Unity 기본 텍스트 필드를 사용합니다. 기존 Input System과 기본 입력을 함께 사용하는 Both 설정을 적용했으므로 Unity를 재시작한 후 확인하세요.

- BFG 발사/핵폭발/사막/돈 갑옷 전환 중 자막을 제거했습니다. 비서의 무기 전달 안내는 유지합니다.

### 2026-11-13 콤보 스킬과 도입 선택

첫 메뉴의 **사무실 파괴**를 누르면 주말 출근 이야기와 선택지가 나타납니다. **닥치고 출근하기**는 상사들의 몽둥이·음파·서류 공격을 받고 쓰러지는 결말로 끝나며, 첫 메뉴 또는 다시 선택하기를 고를 수 있습니다. **사무실 파괴하기**는 1층부터 본 게임을 시작합니다.

| 무기 | 일반 물건 파괴 3콤보 후 F키 (10초 안에 발동) |
| --- | --- |
| 야구빠따 | 10초 휠윈드 |
| 망치 | 10배 크기의 토르의 망치, 전방 직선 번개 1회. 번개 피해 180, 사거리 30m, 폭 3m. 1.2초 뒤 원래 크기로 복귀 |
| 권총 | 10초간 얼음 총알. 생존한 피격 유닛은 3초간 이동/공격 정지, 재명중 시 3초로 갱신 |

스킬을 발동하면 기존 콤보를 소비합니다. 휠윈드·번개·얼음탄·지속 화상 피해는 파괴 진행과 기본 점수에는 반영하지만, 콤보·추가 시간·스킬 재충전을 발생시키지 않습니다. 권총 스킬의 10초는 다른 무기를 들어도 흐릅니다. 일시정지와 연출 중에는 스킬 시간이 멈추며, 새 게임과 층 이동 때 스킬 상태를 초기화합니다.

새 코드: `OfficeRampageGame.Elements.cs`(스킬/콤보 제외), `OfficeDefender.Frozen.cs`(동결), `OfficeRampageGame.Intro.cs`(도입/출근 결말).
