# Office Rampage — 사무실 파괴

주말 출근을 강요받은 직장인이 사무실을 돌파하는 **Unity 3D 3인칭 액션 게임**입니다.

- **스토리 모드:** 퇴근을 막은 단말기와 업무 서버를 부수고, 임원과 지원 인원을 넘어 대표에게 도전합니다.
- **무한 파괴 모드:** 바닥에서 무기와 방어 장비를 주우며 끝없이 등장하는 적을 상대하고 생존 기록을 겨룹니다.

**2026-11-26 구현 기준.** 스토리 확장 1~4차와 전투 HUD 개편이 반영되었습니다. 단계별 기획과 구현 현황은 [스토리 기획서](Docs/STORY_MODE_PLAN.md), 작업별 변경 사항은 [업데이트 기록](OfficeRampage_Update.md)에서 관리합니다.

## 실행 환경과 시작

| 항목 | 설정 |
| --- | --- |
| Unity Editor | 6000.5.1f1 |
| 렌더링 | Universal Render Pipeline 17.5.0 |
| 입력 | Input System 1.19.0, Active Input Handling = Both |
| 시작 씬 | `Assets/OfficeRampage/Scenes/OfficeRampage.unity` |
| UI | 1280×720 기준 비례 확대 IMGUI, 월드 TextMesh |

1. Unity Hub에서 프로젝트를 열고 위 Editor 버전을 사용합니다.
2. 시작 씬을 열거나 **Tools → Office Rampage → Open Game Scene**을 선택합니다.
3. Play를 누른 후 Game 창을 클릭합니다.
4. **스토리 모드** 또는 **무한 파괴 → 생존 시작**을 선택합니다.

첫 메뉴의 **스토리**는 배경 설명 페이지입니다. 실제 게임은 **스토리 모드**에서 시작합니다. 코드 변경이 바로 보이지 않으면 Play를 종료하고 Unity에서 Refresh한 뒤 다시 실행하세요.

## 조작

| 입력 | 기능 |
| --- | --- |
| WASD / 마우스 | 이동 / 시점·조준 |
| Space | 점프 |
| 왼쪽 Shift + 이동 | 달리기, 최대 10초 |
| 왼쪽 클릭 | 공격·소환 무기 사용·로봇 탑승·조준한 더미 투척 |
| 오른쪽 클릭 | 스토리 더미 조준·취소 / 무한 모드 로봇 대쉬 |
| F | 준비된 현재 무기의 콤보 스킬 |
| 숫자키 1~8 | 스토리 무기 전환 |
| E | 스토리 퇴근 요청·동료 구출 / 무한 모드 장비·보급 획득 |
| Esc | 일시정지·재개 |
| M | 전체 음소거 |

재게임은 결과 화면에서 선택합니다. R키로 첫 스테이지로 돌아가는 기능은 없습니다. 무한 모드의 무기 전환은 바닥 장비를 주울 때만 가능합니다.

달리기는 게이지와 다리 움직임·바람 효과로 표시합니다. 기본 회복 속도는 초당 2초분이며, 모두 소진하면 Shift를 놓고 최소 2초분을 회복해야 다시 달릴 수 있습니다.

## 설정과 회사 구성

설정에서 음악·효과음 음량과 전체 음소거를 조절합니다. **유닛 설정**에서는 직급별 인물의 이름과 성별을 바꿀 수 있습니다. 이름은 최초 무작위 지정되며 최대 24자, 수정 사항은 저장 후 새 게임부터 반영됩니다.

| 직급 | 사원 | 주임 | 대리 | 과장 | 차장 | 부장 | 이사 | 상무 | 전무 | 부사장 | 대표 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 고정 인원 | 10 | 8 | 6 | 5 | 4 | 3 | 2 | 2 | 1 | 1 | 1 |

3층의 추가 운전기사·비서·결재 담당과 대표층 호위는 별도 고정 인원입니다. 추가 지원 역할은 고정 이름을 사용합니다. 기존 임원들의 이름·성별 설정은 유지됩니다.

스토리에는 시간 제한이 없습니다. 과거의 1/2/3분 제한과 콤보 시간 추가 규칙은 사용하지 않습니다.

## 스토리 모드

### 도입과 진행 목표

36초 공통 프롤로그에서 **금요일 야근 → 토요일 출근 메시지 → 퇴근 권한 거부**를 보여줍니다. 건너뛰기를 누르면 선택 화면으로 이동합니다.

- **닥치고 출근하기:** 상사들에게 둘러싸여 업무 지시와 집중 공격을 받다가 ‘업무 스트레스로 사망’으로 끝납니다. **이번에는 참지 않기**를 누르면 프롤로그 반복 없이 파괴 경로를 새로 시작합니다.
- **사무실 파괴하기:** 1층 로비에서 시작해 퇴근 승인권자를 찾아 올라갑니다.

| 층 | 필수 목표 | 진행 조건 |
| --- | --- | --- |
| 1층 로비 | 퇴근 승인 단말기와 보안 대응 인원 3명 | 단말기 파괴 + 지정 인원 처치 |
| 2층 사무실 | 업무 서버 3개와 방어 담당 3명 | 서버 파괴 + 지정 인원 처치. 동료 구출은 선택 |
| 3층 임원층 | 임원 6명과 지원 인원 12명 | 6명씩 세 차례 전투를 모두 완료 |
| 4층 대표층 | 경비견 → 보디가드 → 대표 | 호위를 순서대로 처치한 뒤 대표와 전투 |

일반 가구 파괴 비율은 이동 조건이 아닙니다. 1층의 비지정 직원, 2층의 비지정 직원·증원을 모두 처치할 필요는 없습니다. **3층은 각 전투의 지원 인원까지 정리해야 합니다.** 엘리베이터로 이동하면 이전 층의 적·가구·투사체 등을 제거합니다.

### 1층 퇴근 거부

단말기 가까이에서 **E**를 누르면 퇴근이 거절되고 ‘근무 태도 이상자’로 등록되면서 전투가 시작됩니다. 주황색 **[보안 대응]** 인원 3명과 단말기를 정리하면 출구가 열립니다.

단말기나 직원을 먼저 공격해도 전투가 시작됩니다. 단말기 파괴와 지정 인원 처치의 순서는 자유입니다. 단말기 기록은 다음 승인 담당자가 **2층 운영팀**임을 알려줍니다.

### 2층 업무 서버와 동료 구출

| 서버 | 작동 중 | 파괴 효과 |
| --- | --- | --- |
| 업무 배정 | 9초마다 증원, 살아 있는 증원 최대 2명 | 추가 증원 중단 |
| 보고서 반려 | 3초마다 서류 3장 발사 | 서류 지원 공격 정지 |
| 근태 조작 | 동료 구역 잠금 | 동료 구역 개방 |

서버는 기존 무기로 원하는 순서대로 파괴할 수 있습니다. 주황색 **[방어 담당]** 3명도 처치해야 엘리베이터가 열립니다. 마지막 서버에서 임원회의 결의서를 발견합니다.

근태 서버 파괴 후 동료 **3m 이내에서 E**를 누르면 구출합니다. 구출 보상은 **3층 입구의 추가 회복 보급**, 그리고 **대표전 중 체력 70 이하일 때 한 번 체력 +30 지원**입니다. 구출하지 않아도 진행할 수 있습니다.

### 3층 임원과 지원 인원

총 18명이 **임원 2명 + 운전기사 2명 + 수행 비서 1명 + 결재 담당 1명**씩 등장합니다. 현재 여섯 명을 모두 처치하면 2초 후 다음 전투가 시작됩니다. 대기 중인 다음 인원은 피해·기절·빙결의 영향을 받지 않습니다.

| 전투 | 임원 체력 | 공격과 공략 |
| --- | ---: | --- |
| 보고서 담당 | 각 180 | 종이 7장을 70도 부채꼴로 발사 |
| 정신력 담당 | 각 220 | 반경 8m까지 퍼지는 원형 음파. 피하거나 점프로 넘긴 뒤 1.4초 회복 동작 중 반격 |
| 책임 회피 담당 | 각 260 | 음파와 종이 다발을 번갈아 사용 |

| 지원 역할 | 총인원 | 체력 | 기능 |
| --- | ---: | ---: | --- |
| 운전기사 겸 수행원 | 6 | 80 | 근접 공격과 밀치기 |
| 수행 비서 | 3 | 65 | 종이 5장·60도 범위 공격 |
| 결재 담당 | 3 | 90 | 같은 전투의 임원에게 보호막 제공, 종이 5장·60도 지원 공격 |

**결재 담당을 먼저 처치하면 임원 보호막이 즉시 해제됩니다.** 종이 공격은 0.9초, 원형 음파는 1.1초 동안 바닥에 범위를 예고합니다. 종이 조준 방향은 준비 동작 시작 시 고정됩니다. 다발 공격 변경은 3층 역할에 적용되며 다른 층·무한 모드의 종이 공격은 유지됩니다.

임원들은 패배하면서 상위 직급에 책임을 넘깁니다. 마지막 전투를 끝내면 결의서와 대표실 접근 권한을 얻고 출구가 열립니다. 이 층의 수행 비서는 대표층에서 BFG18을 주는 비서와 별도 인물입니다.

### 엘리베이터 보상과 회복

1→2층, 2→3층, 3→4층 이동마다 아래 보상 중 하나를 선택합니다. 선택 중에는 전투와 시간이 멈춥니다. Esc로 일시정지했다 돌아와도 선택을 계속할 수 있습니다.

| 보상 | 효과 | 누적 규칙 |
| --- | --- | --- |
| 법인카드 | 권총 200발·샷건 100발·로켓 20발로 보충 | 반복 선택 가능. 더미·비밀 무기 제외 |
| 산재 처리 | 최대 체력 +20, 현재 체력 +40 | 최대 체력 상한 160 |
| 퇴근 본능 | 달리기 게이지 회복 속도 +25% | 합산 상한 +75%, 달리기 지속시간은 10초 유지 |

기본 최대 체력은 100입니다. 층별 기본 포션은 2개이며 하나당 30 회복, 정수기는 파괴하면 5 회복합니다. 최대 체력 보상은 체력바와 회복 상한에 반영됩니다. 전자제품은 파괴 시 폭발 위험이 있습니다.

보상과 구출 상태는 층을 이동해도 유지됩니다. 새 게임·재게임·무한 모드 시작 시 초기화되며 영구 성장으로 저장하지 않습니다.

### 4층 대표전과 퇴근 엔딩

1. **경비견 5마리**를 처치합니다.
2. **보디가드 5명**을 처치합니다. 몽둥이 2명·권총 2명·장거리 샷건 1명입니다.
3. 대표와 전투합니다. 호위 구간을 끝낼 때 경계 벽과 문이 사라집니다.

인간 대표는 체력 **50% 이하에서 붉은 분노 오라**와 함께 강화됩니다. **20% 이하에서 비서가 BFG18을 제공**합니다. 두 발동 조건은 서로 다릅니다.

BFG18 사용 후 건물 붕괴·폭발과 사막 전환, 우주에서 투하되는 거대 로봇 탑승으로 이어집니다. 로봇 대표는 광선검·돌진·원거리 공격을 사용합니다. 로봇 탑승 직후 플레이어의 권총·샷건·로켓 탄약은 다시 보충됩니다.

로봇 체력 20% 이하에서는 빨간 버튼 **???**가 등장합니다. 위성 레이저와 지구 분리 연출, 로봇 파괴와 대표가 밖으로 튕겨 나오는 장면으로 이어집니다.

대표와 비서는 호위 구간, 분노, BFG18 전달 때 짧은 대사를 합니다. 로봇은 직원 복지 예산으로 만든 장비이며, 3층에서 얻은 결재 권한으로 위성 장비를 사용한다는 이야기가 연결됩니다.

대표의 마지막 무작위 대사 후 출입구로 이동합니다. **퇴근 승인 → 문 열림 → 월요일 오전 9시 긴급회의 알림 → 휴대전화를 뒤집고 퇴근** 순서입니다. 비서는 함께 떠나며, 2층에서 구출한 동료가 있다면 동료도 동행합니다.

엔딩의 **확인**은 첫 메뉴, **재게임**은 1층부터 새 게임, **무한 파괴로 스트레스 더 풀기**는 무한 모드로 이동합니다. 대표전 무기 전달·우주 연출·퇴근 장면은 **Space**로 건너뛸 수 있습니다. 건너뛰어도 무기 지급과 페이즈 전환은 완료됩니다.

일반 공격으로 가구를 부수거나 적을 처치하면 콤보가 쌓입니다. 4초 안에 이어가지 못하면 초기화됩니다. 방망이·망치·권총은 3콤보 단위로 스킬이 준비되고, 준비 후 10초 안에 해당 무기로 F를 눌러 사용합니다.

**스킬 피해는 콤보를 재충전하지 않습니다.** 휠윈드·낙뢰·얼음탄·지속 화상·소환 지원으로 스킬을 무한 충전할 수 없습니다. 얼음탄은 권총 탄약을 소비합니다.

더미는 남성 직원을 유인하며 여성·대표·경비견은 면역입니다. 무한 모드에는 더미가 등장하지 않습니다. 일반 탄약은 층 이동 시 유지되며 새 게임, 법인카드 선택, 대표의 로봇 탑승 시 보충됩니다.

## 무한 파괴 모드

### 생존과 보급

64m 전장에서 생존 시간·처치 수·점수를 기록합니다. 시작 무기는 **광선검**이며 피해와 휠윈드 스킬은 방망이와 같습니다.

- 장비 2.5m 이내에서 **E**를 누르면 즉시 교체합니다. 인벤토리 보관이나 숫자키 전환은 없습니다.
- 탄약이나 일회용 사용량이 소진되면 기본 광선검으로 복귀합니다.
- 적은 시작 5초 뒤부터 한 번에 2명씩 생성됩니다. 시간에 따라 생성 간격과 체력이 강화되며 동시 상한은 80명입니다.
- 일반 무기는 3초마다 보급합니다. BFG·위성 호출기는 30초 이후 일반 보급 후보에 포함됩니다.
- 지진 유발기와 운석 소환기는 각각 별도의 30초 주기로 보급합니다.
- 회복·갑옷 보급은 8초 주기이며, 14% 확률로 피해 2배 아이템이 나옵니다. 바닥 보급 상한은 18개입니다.
- 회복은 체력 +30, 갑옷은 내구도 +60이며 상한은 각각 100입니다. 갑옷은 내구도 범위에서 피해의 70%를 흡수합니다.
- 가구도 재생성됩니다. 전자제품 폭발은 주변 적을 공격하는 함정으로 활용할 수 있습니다.

### 환경과 피해 2배

광장에서 시작해 첫 전환은 사막, 이후 무인도와 사막이 번갈아 나옵니다. 생존 시간 **5분·10분·15분…**마다 전환하며, **BFG18·위성·헐크버스터·전투기·블랙홀·지진·운석** 사용도 배경 전환을 일으킵니다.

무기로 배경이 바뀌어도 정기 5분 주기는 유지됩니다. 배경 변경 자체는 체력·기록·장비를 초기화하지 않으며, 이동 경계 밖의 바다나 먼 모래언덕에는 갈 수 없습니다.

피해 2배 아이템은 20초간 적·가구에 주는 피해를 두 배로 만듭니다. 획득 고리·효과음, 발밑 보라색 오라, **×2와 남은 시간 게이지**로 표시합니다. 마지막 3초에는 색이 바뀌고, 재획득하면 시간을 갱신하며 4배로 중첩하지 않습니다.

### 결과와 로컬 Top 10

게임 종료 후 한글을 포함해 최대 24자의 이름을 입력하고 **기록 등록**을 누르면 로컬 Top 10에 저장됩니다. 등록하지 않고 재도전할 수도 있습니다.

**종합점수 = 게임 점수 + 생존 초 × 10 + 처치 수 × 100**

동점은 생존 시간 → 처치 수 → 게임 점수 → 먼저 등록한 기록 순으로 정렬합니다. 같은 이름의 여러 판은 각각 기록하며 합산하지 않습니다. **무한 파괴 → Top 10 랭킹**에서 확인합니다. 온라인 공용 랭킹이 아닙니다.

두 모드 모두 **상단 한 줄 정보, 좌하단 체력, 우하단 현재 무기**를 사용합니다. 무한 모드는 갑옷도 표시합니다.

- 무한 상단: 생존 시간·처치·점수·콤보·적 수·최고 생존 기록
- 스킬·달리기·상태 이상: 아이콘과 숫자·게이지
- 스토리 대사: 상단 바로 아래의 짧은 자막
- 대표 체력: 작은 체력 타일과 얇은 막대

스토리의 이전 8칸 무기창은 현재 무기 카드로 교체했습니다. 숫자키 1~8 전환은 그대로 사용할 수 있습니다. 엘리베이터 보상은 전투가 멈춘 상태에서 별도의 선택 화면으로 표시합니다.

## Web과 한글 폰트

OS 설치 폰트를 가져오지 않고 `Assets/Fonts/NotoSansKR-VariableFont_wght.ttf`를 사용합니다. `OfficeGameFont`가 Resources의 `GameFont.asset`을 읽으며, 이 자산이 원본 TTF를 참조해 빌드에 포함합니다.

- IMGUI 메뉴·HUD·입력창과 월드 TextMesh에 공통 폰트를 적용합니다.
- TextMesh의 `font`와 `MeshRenderer.sharedMaterial`을 함께 연결합니다.
- TTF의 **Dynamic / Include Font Data**와 `GameFont.asset`의 Font 참조를 유지합니다.
- 실패 로그는 `[OfficeFont]`로 확인합니다. 기존 이름 입력과 IME 처리는 유지합니다.

이전 폰트 수정 시 Editor의 한글·영문·숫자와 별도 Web 개발 빌드를 확인했습니다. **최근 스토리 1~3차와 HUD 변경은 Unity 컴파일·Play 검증 기준이며, 최신 Web 빌드·브라우저 화면·브라우저 한글 조합 입력까지 검증한 상태는 아닙니다.**

배포 전 최신 코드로 Web을 빌드하고 HTTP(S)로 실행해 메뉴·이름표·숫자·한글 입력·전투 진행·저장을 확인하세요. 고정 굵기 TTF 교체 방법과 폰트 상세 보고서는 [Web 폰트 문서](Docs/WEB_FONT_FIX.md)에 있습니다.

## 검증과 개발 상태

스토리 1~3차는 격리된 Unity 6000.5.1f1 프로젝트에서 컴파일·Play 검사를 수행했습니다. 주요 확인 범위는 다음과 같습니다.

- 이동·점프·바닥·벽 충돌과 도입 선택·재도전
- 로비 목표 처리 순서, 2층 서버 파괴 순서 6가지, 구출·미구출 진행
- 실제 1→2→3→4층 엘리베이터 이동, 보상 유지·중복 방지·일시정지·초기화
- 3층 인원 구성·순차 전투·보호막·종이 다발·음파·최종 출구 조건
- 스토리 HUD와 보상 화면, 대표층·무한 모드와의 상태 분리

코드를 수정하면 **컴파일 → 기본 이동·충돌 → 변경 기능 → 실제 배포 플랫폼** 순서로 확인합니다. 자동 Play 검사 통과와 사람의 수동 플레이·난이도 평가는 구분합니다.

스토리 기획의 다음 작업은 **대표·비서 대사 보강과 새 퇴근 결말**입니다. 현재 구현으로 오해하지 않도록 [기획서 체크리스트](Docs/STORY_MODE_PLAN.md)를 함께 갱신합니다.
