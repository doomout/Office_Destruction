# Office Rampage — 사무실 파괴 게임 첫 버전

Unity 6000.5.1f1 / URP / Input System으로 만든 3인칭 플레이용 프로토타입입니다.
기존 SampleScene, CodexStarter, 프로젝트 설정은 변경하지 않았습니다.

## Unity에서 실행

1. Unity로 돌아가 파일 가져오기와 스크립트 컴파일이 끝날 때까지 기다립니다.
2. `Tools > Office Rampage > Open Game Scene`을 선택합니다. 또는 Project 창에서
   `Assets/OfficeRampage/OfficeRampage.unity`를 더블클릭합니다.
3. 기존 씬 저장 여부를 물으면 작업에 맞게 저장합니다.
4. 상단 ▶ Play를 누르고 Game 화면을 클릭합니다.
5. 편집 상태에서는 생성기 오브젝트 하나만 보이는 것이 정상입니다. 플레이를 시작하면 맵, 캐릭터, 카메라, 조명이 생성됩니다.

## 조작

| 입력 | 기능 |
| --- | --- |
| WASD | 카메라 방향 기준 이동 |
| 마우스 | 시점 / 조준 |
| 왼쪽 클릭 (누르고 있어도 가능) | 공격 |
| Space | 점프 |
| 왼쪽 Shift | 달리기 |
| 1 | 해머: 근거리 범위 공격 |
| 2 | 산탄총: 7발 산탄 |
| 3 | 로켓 런처: 조준 지점에 즉시 폭발하는 범위 공격 |
| Esc | 일시정지 / 재개, 마우스 잠금 해제 |
| R | 랜덤 배치를 새로 생성하고 처음부터 재시작 |

게임 창에서 포커스를 잃으면 자동으로 일시정지됩니다. 다시 클릭하고 Esc 또는 RESUME으로 재개합니다.

## 게임 규칙

- 시작 시간 120초, 체력 100. 무기 탄약은 이 첫 버전에서는 무제한입니다.
- 너비와 깊이가 다른 사무실이 총 5개 이어집니다. 다음 문에 접근하면 다음 사무실을 생성합니다.
- 책상, 컴퓨터가 있는 책상, 정수기, 프린터가 랜덤으로 배치됩니다.
- 중앙 통로와 문 앞은 비워 두어 항상 다음 방까지 이동할 수 있습니다.
- 물건의 60% 이상을 파괴하면 주황색 출구가 청록색으로 바뀌며 열립니다.
- 화면 왼쪽의 DESTROY 숫자는 현재 파괴 수 / 문을 여는 데 필요한 파괴 수입니다.
- 마지막 파괴 후 4초 안에 다음 물건을 부수면 콤보가 이어집니다.
- 콤보 3, 6, 9…마다 제한 시간이 5초 증가합니다. 4초가 지나면 콤보가 초기화됩니다.
- 방 5개를 통과하면 사장과 1:1 전투를 합니다. 주황색 바닥 표시가 돌진 경고입니다.
- 사장은 추격 → 돌진 예고 → 돌진 → 휴식 순서로 행동합니다. 휴식 중에는 접촉 피해가 없습니다.
- 사장 체력 900을 소진하면 승리. 시간 또는 플레이어 체력이 0이면 패배합니다.
- R이나 결과 화면의 PLAY AGAIN으로 다시 시작할 수 있습니다.

## 구현 범위

캐릭터와 사무집기는 기본 도형으로 만든 임시 모델입니다. 화난 표정, 정장, 무기 외형,
파괴 파편, 공격 궤적, 화면 흔들림, 목표/시간/체력/점수/콤보 UI가 포함됩니다.
컴퓨터와 해당 책상은 하나의 파괴 단위입니다. 로켓은 탄도 비행 없이 즉시 판정합니다.
파편에는 충돌을 넣지 않아 이동을 방해하지 않으며, 최대 70개만 잠깐 유지합니다.
전문 모델, 사운드, 애니메이션 클립, 저장 기능, 실행 파일 배포는 포함하지 않았습니다.
게임 내부 안내는 폰트 의존성을 줄이기 위해 영어로 표시합니다.

## 플레이 확인 순서

1. Console에 빨간 컴파일 오류가 없는지 확인합니다.
2. Play에서 WASD 이동과 마우스 회전을 확인합니다.
3. Space 점프 후 바닥으로 정상 착지하는지 확인합니다.
4. 벽과 책상에 막히는지, 열린 문은 통과하는지 확인합니다.
5. 무기 1/2/3으로 파괴하고, 3연속 파괴 시 +5초가 적용되는지 확인합니다.
6. 사무실 5개 → 사장 등장 → 승리/패배 → R 재시작을 확인합니다.

실제 수행한 검사 결과는 프로젝트 루트 `OfficeRampage_검증.md`를 참고하세요.
