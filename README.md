# Office Rampage — 사무실 파괴

직원들과 싸우고 사무집기를 부수며 대표에게 도전하는 3인칭 액션 게임입니다. 사무실은 Unity에서 직접 편집하는 층별 프리팹을 불러오고, 인간 캐릭터는 무료 Kenney 모델을 사용합니다. 무기·효과는 코드 생성 방식이며 가구·벽·배경 모델은 층 프리팹에 저장됩니다. 이 문서는 **2026-11-17 현재 구현**을 기준으로 합니다.

## 실행

1. Unity Hub에서 이 프로젝트를 **Unity 6000.5.1f1**로 엽니다.
2. `Assets/OfficeRampage/Scenes/OfficeRampage.unity`를 열거나 **Tools → Office Rampage → Open Game Scene**을 선택합니다.
3. Play를 누른 뒤 Game 창을 클릭합니다.
4. 첫 메뉴 → **스토리 모드**에서 기존 도입 이야기를 시작하거나, **무한 파괴 → 생존 시작**으로 별도 생존 전장을 엽니다.

URP 17.5.0, Input System 1.19.0을 사용합니다. 입력 설정은 **Both**이며, 게임 조작은 Input System, 한글 이름 입력은 기본 TextField/IME를 사용합니다.

## 무한 파괴 모드

3D 전장에서 적이 계속 등장하고 가구가 재생성됩니다. 바닥에서 **E**로 무기·갑옷·회복 보급을 주우며 생존합니다. 무기는 줍는 순간 교체되며 숫자키 교체는 차단됩니다. 기존 8종과 사무용품 특수 무기 6종, 생존 기록을 제공합니다. [무한 파괴 안내와 수정 위치](Docs/ENDLESS_MODE.md)를 참고하세요.

## 층 디자인 편집

Play를 끈 뒤 **Tools → Office Rampage → Floors → 원하는 층 편집**을 선택하세요. 가구·벽·직원 시작점을 W/E/R로 편집하고 Ctrl+S로 저장합니다. 정상 게임은 이 프리팹을 그대로 사용합니다. [그림으로 층 편집하기](Docs/VISUAL_FLOOR_EDITING.md)에 전체 절차와 주의사항을 정리했습니다.

## 조작

| 입력 | 동작 |
| --- | --- |
| WASD / 마우스 | 이동 / 시점 |
| Space | 점프 |
| 왼쪽 Shift + 이동 | 최대 10초 달리기 |
| 왼쪽 클릭 | 공격, 더미 조준 중 투척 |
| 오른쪽 클릭 | 더미 조준/취소 및 점선 궤적 |
| 1~8 | 스토리 모드 무기 선택 (8은 BFG 획득 후); 무한 파괴에서는 사용 불가 |
| E | 무한 파괴 바닥 장비 줍기/교체 |
| F | 현재 무기의 준비된 콤보 스킬 |
| Esc | 일시정지/재개 |
| M | 전체 음소거 |

달리기 게이지는 초당 2초분씩 회복합니다. 완전히 소진하면 Shift를 놓고 최소 2초분을 회복한 뒤 다시 사용합니다.

## 시작 이야기와 메뉴

- **사무실 파괴하기:** 1층에서 정상 게임 시작.
- **닥치고 출근하기:** 전체 직원 43명이 3겹으로 포위해 12초 이상 집중 공격합니다. 쓰러진 뒤 **업무 스트레스로 사망**과 첫 메뉴/다시 선택하기 버튼이 표시됩니다.
- **설정:** 음악·효과음·음소거·인물별 이름/성별 설정.
- **스토리:** 배경 설명. **무한파괴:** 현재 준비 중인 안내 화면입니다.

## 4개 층과 진행 방식

시간 제한과 시간 난이도 설정은 제거했습니다. **가구를 부술 필요 없이 직원 전원을 처치하면** 엘리베이터가 열립니다. 이전 층은 이동 후 메모리에서 제거하며 되돌아가지 않습니다.

| 층 | 고정 배치 | 인원 / 진행 |
| --- | --- | --- |
| 1층 | 가구 없는 로비 | 사원 10명 · 각 체력 100 |
| 2층 | 마주 보는 책상 묶음, 의자, 복합기, 수납장 | 주임~부장 26명 |
| 3층 | 파티션 없는 임원 업무 공간 | 이사~부사장 6명 |
| 4층 | 경비견실 → 보디가드실 → 대표실·비서실 | 경비견 5마리 전멸/첫 구역 벽 제거 → 보디가드 5명 전멸/둘째 구역 벽 제거 → 대표 |

가구 파괴는 선택이며 전자기기는 폭발 함정입니다. 기본 파괴 콤보와 스킬 충전은 유지하지만 시간 보너스는 없습니다. 체력은 최대 100, 각 층 포션 2개는 30씩 회복합니다. 정수기 파괴는 +5, 전자기기 파괴는 거리와 무관하게 -5입니다. 체력 0이면 패배합니다.

## 무기와 스킬

| 키 | 무기 | 특징 |
| --- | --- | --- |
| 1 | 야구빠따 | 근접 피해 40, F 스킬은 10초 휠윈드 |
| 2 | 망치 | 근접 피해 90, F 스킬은 망치를 들어 3초간 연속 낙뢰, 사람 3초 기절 |
| 3 | 권총 | 200발, 피해 32/사거리 24, F 스킬은 10초 얼음탄·피격 유닛 3초 동결 |
| 4 | 기관총 | 발당 피해 12, 빠른 연사 |
| 5 | 미인계 더미 | 층당 3회, 착지 후 10초 남성 직원 유인. 여성·대표·경비견 면역 |
| 6 | 불 속성 샷건 | 100발, 권총과 같은 단일 타격 + 5초간 초당 1 화상 피해 |
| 7 | 로켓런처 | 20발, 직진 화염 꼬리, 폭발 피해 120/반경 4.5 |
| 8 | BFG 18 | 대표전에서 획득하는 1회용 핵폭발 무기 |

방망이·망치·권총은 해당 일반 공격으로 3콤보 단위에 도달하면 스킬이 준비되며, 10초 안에 해당 무기를 들고 F를 누릅니다. 발동 시 콤보를 소비합니다. 망치 스킬은 크기를 키우지 않고 치켜드는 자세로 3초 동안 6차례, 매번 3개의 낙뢰를 소환합니다. 14m 내 보이는 적을 우선하며 낙뢰 반경 1.7m의 사람은 12 피해와 3초 기절(재명중 시 갱신), 물건은 18 피해를 받습니다. 경비견은 번개 피해만 받고 기절하지 않습니다. 얼음탄 재명중은 동결을 3초로 갱신합니다.

**휠윈드·번개·얼음탄·지속 화상은 콤보, 스킬 재충전을 만들지 않습니다.** 기본 점수와 적 처치는 반영합니다. 권총 200발·샷건 100발·로켓런처 20발은 새 게임 시작 시 지급하며 층 이동 시 잔탄을 유지합니다. 로봇 탑승 직후에는 이 세 무기의 탄약을 전부 보급합니다. 얼음탄도 권총 탄약을 소비합니다. 방망이·망치·기관총은 무제한, 더미는 층당 3개, BFG는 획득 후 1회입니다.

## 우리 회사 인물 설정

설정 → 유닛 설정에서 직급을 고르고 각 인물의 이름과 성별만 바꿉니다. 인원은 고정이며 처음 이름은 무작위입니다. 한글 이름은 최대 24자, 편집창에서 적용 후 유닛 설정에서 저장합니다. 저장 결과는 다음 새 게임부터 반영됩니다.

| 층 | 구성 | 엘리베이터 처치 목표 |
| --- | --- | --- |
| 1 | 사원 10, 주임 8 | 11/18 |
| 2 | 대리 6, 과장 5 | 7/11 |
| 3 | 차장 4, 부장 3 | 5/7 |
| 4 | 이사 2, 상무 2, 전무 1, 부사장 1 | 4/6 |
| 5 | 대표 1, 경비견 5, 숨겨진 경비 5 | 경비견 전원 → 경비 전원 처치 후 대표 활성화 |

인간 총 43명입니다. 경비는 현재 생성/설정에서 제외되어 있지만 코드는 보존했습니다. 성별에 따른 체력·피해·충돌 크기는 같고 외형과 더미 반응이 다릅니다.

## 대표전과 엔딩

대표는 몽둥이·음파·서류를 사용하고 체력이 절반 이하가 되면 몸을 붉은 에너지 오라가 감싸며 분노해 속도/범위가 50% 증가합니다. 비서실에서 떨고 있던 비서는 대표 체력 20% 이하에서 문을 통해 나와 BFG 18을 전달한 뒤 돌아가 사라집니다. 핵폭발 때 벽·천장이 132개 파편으로 갈라져 튕겨 나가 추락하며 버섯구름 후 사무실보다 넓은 경계가 있는 사막으로 전환되고, 지구 밖 우주 수송대에서 거대 로봇을 투하하고, 대기권 진입 장면 뒤 사람의 약 3배 크기로 사막에 착륙하며 대표가 조종석에 탑승합니다. 사막의 가로·세로는 이전 사막의 각각 2배(원래 사무실의 각각 2.5배)입니다. 로봇의 현재/최대 체력은 `(전환 직전 체력 + 인간 최대 체력의 50%) × 2`이며, 20%에서 바로 BFG를 쓰면 700입니다. 로봇은 빠른 광선검·돌진·3방향 플라스마 공격을 사용합니다.

대표 처치 후 쓰러지는 동작과 무작위 마지막 대사, 확인/재게임 버튼이 나옵니다. 확인은 첫 메뉴, 재게임은 1층 즉시 시작입니다. BFG 폭발·사막 전환 자막은 제거했고 비서 전달 안내는 유지합니다.

## 유지보수와 검사

폴더만 분리했으며 기존 스크립트/씬의 `.meta` GUID를 보존합니다. `OfficeRampageGame.*`는 여러 파일에 나눈 하나의 partial 클래스이므로 서로 다른 폴더에서도 함께 컴파일됩니다. Unity 버전·패키지·입력 설정을 유지하고, 실제 검사 결과는 [업데이트 기록](OfficeRampage_Update.md)에 남깁니다.

한글 입력은 사용자 플레이에서 정상 동작이 확인되었습니다. 자동 검사는 게임 규칙과 진행 흐름을 확인하며, 새 그래픽/음악의 품질·손맛·모든 해상도는 직접 플레이해서 확인해야 합니다.


## 고정 사무실과 새 캐릭터

층별 가구·벽·배경과 인물/포션 시작 위치는 `Resources/OfficeFloors/Floor1.prefab`~`Floor4.prefab`에 저장합니다. JSON은 이전 배치와 복구용이며 정상 플레이는 프리팹을 우선 사용합니다.

인간 캐릭터는 [Kenney Mini Characters 2.0](https://kenney.nl/assets/mini-characters)의 남성 6종/여성 6종을 사용합니다. CC0 라이선스 원문과 출처를 `Art/KenneyMiniCharacters`에 보관했습니다. 주인공·직원·대표·비서·더미·출근 군중에 적용되며, 개방형 사무실 가구와 경비견 모델은 기존 방식입니다. 걷기/달리기/공격 애니메이션을 연결하고 기존 충돌 크기·체력·무기·스킬 규칙은 유지합니다.

모델 목록은 `Resources/OfficeCharacters/Catalog.asset`에서 바꿀 수 있습니다. 자세한 적용 조건과 고정 배치 편집 방법은 [가이드](Docs/ASSET_GUIDE.md)를 참고하세요.


## 무기 아이콘과 실내 연출

하단 무기창은 8개 실루엣 아이콘으로 표시하며, 각 칸의 숫자는 남은 탄약/더미/BFG 횟수입니다. 무제한 무기는 ∞, 탄약이 없거나 BFG를 사용할 수 없으면 아이콘이 흐려집니다. 무기 선택 키는 1~8입니다.

사무실에는 높이 11.6m 천장, 천장 조명 패널, 창틀과 창밖 도시 건물을 추가했습니다. 창밖은 배경이며 기존 경계를 넘어갈 수 없습니다. 위에서 내려다보는 출근·핵폭발 카메라에서는 지붕과 벽 외형을 숨겨 연출이 가리지 않게 합니다. 다음 층 이동/사막 전환 시 함께 정리됩니다.

출근 결말의 43명은 더 넓은 3겹(반경 4.8/7.9/11m)으로 포위합니다. 12초 동안 ‘감히 어제 퇴근을 해?’, ‘라떼는 말이야~ 사무실에서 살았어!’ 등 8개 대사가 순서대로 나온 뒤 기존 사망 화면으로 이어집니다.

### 대표 호위 2차 전투
경비견 5마리를 모두 처치하면 첫 구역을 나누던 벽과 문이 사라지고 보디가드 5명이 등장합니다. 몽둥이 2명(체력140, 근접), 권총 2명(체력120, 사거리12m), 장거리 샷건 1명(체력160, 사거리22m/5발 산탄)입니다. 보디가드도 전원 처치해야 둘째 구역을 나누던 벽과 문이 사라지고 대표의 무적이 해제됩니다. 설정창의 직원 인원/명단은 바뀌지 않습니다. 대표층은 호위전도 시간 무제한입니다.

### 최종 비밀 무기와 재시작
R키는 아무 동작도 하지 않습니다. 재시작은 게임 종료 화면의 ‘재게임’ 버튼 또는 첫 메뉴에서 새 게임을 시작하는 방식입니다.

2페이즈 대표 체력이 20% 이하가 되면 ‘???’ 빨간 버튼이 번개와 함께 하늘에서 떨어져 자동 획득됩니다. 큰 한 방으로 이 이벤트를 건너뛰지 않도록 치명타 때만 1 HP로 생존시키고 버튼을 지급합니다. 획득 후에는 일반 무기로 마무리하거나 버튼을 사용할 수 있습니다.


모든 연출은 Esc 일시정지에 따라 멈추며 새 게임에서 로봇/버튼/우주 연출/분화구 상태를 초기화합니다.
