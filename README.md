# Office Rampage — 사무실 파괴

직원들과 싸우고 사무집기를 부수는 **3D 3인칭 액션 게임**입니다. 대표에게 도전하는 **스토리 모드**와 바닥 장비를 주워 끝없이 버티는 **무한 파괴 모드**를 제공합니다.

이 문서는 **2026-11-25 현재 구현**을 기준으로 작성했습니다. 과거 변경 사항은 [업데이트 기록](OfficeRampage_Update.md), 기능별 상세 설명은 아래 안내 문서를 참고하세요.

향후 스토리 확장은 [스토리 모드 확장 기획서](Docs/STORY_MODE_PLAN.md)를 기준으로 진행합니다. 기획서의 1차 도입·2층 목표와 2차 층별 진행·엘리베이터 보상을 적용했으며, 임원 전투 패턴 확장은 다음 단계입니다.

## 1. 실행 환경과 시작 방법

| 항목 | 현재 설정 |
| --- | --- |
| Unity Editor | 6000.5.1f1 |
| 렌더링 | Universal Render Pipeline 17.5.0 |
| 입력 | Input System 1.19.0, Active Input Handling = Both |
| 시작 씬 | `Assets/OfficeRampage/Scenes/OfficeRampage.unity` |
| 화면 구성 | 1280×720 기준 비례 확대 IMGUI + 월드 TextMesh |

1. Unity Hub에서 프로젝트 폴더를 위 Editor 버전으로 엽니다.
2. 시작 씬을 엽니다. **Tools → Office Rampage → Open Game Scene** 메뉴로도 열 수 있습니다.
3. Play를 누르고 Game 창을 클릭합니다.
4. 첫 메뉴에서 **스토리 모드** 또는 **무한 파괴 → 생존 시작**을 선택합니다.

첫 메뉴의 항목은 **스토리 모드 / 무한 파괴 / 설정 / 스토리 / 끝내기**입니다. ‘스토리’는 배경 설명 메뉴이며, 실제 스토리 게임은 ‘스토리 모드’에서 시작합니다. 패키지나 입력 설정을 임의로 변경하지 마세요.

## 2. 기본 조작

| 입력 | 동작 |
| --- | --- |
| WASD | 이동 |
| 마우스 | 시점·조준 |
| Space | 점프 |
| 왼쪽 Shift + 이동 | 달리기, 최대 10초 |
| 왼쪽 클릭 | 공격, 조준한 더미 투척, 소환·탑승 무기 사용 |
| 오른쪽 클릭 | 스토리 더미 조준·취소 / 무한 모드 헐크버스터 대쉬 |
| F | 현재 무기의 준비된 콤보 스킬 |
| 숫자키 1~8 | 스토리 무기 선택 |
| E | 스토리 퇴근 요청·동료 구출 / 무한 모드 바닥 장비·보급품 획득 |
| Esc | 일시정지·재개 |
| M | 전체 음소거 |

무한 모드에서는 숫자키로 무기를 바꿀 수 없습니다. 재도전은 결과 화면이나 메뉴에서 선택합니다.

달리기는 빠른 다리 움직임·바람 효과와 게이지로 표시합니다. 게이지는 초당 2초분씩 회복하며, 모두 소진한 경우 Shift를 놓고 최소 2초분을 회복해야 다시 달릴 수 있습니다.

## 3. 설정과 회사 구성

설정에서 음악·효과음 음량과 전체 음소거를 조절합니다. 현재 게임에는 제한 시간이 없으며, 예전 1/2/3분 난이도 규칙과 콤보 시간 보너스는 사용하지 않습니다.

**설정 → 유닛 설정**에서는 직급별 인물의 이름과 성별을 바꿀 수 있습니다. 이름은 처음에 무작위로 지정되며 최대 24자입니다. 이름 편집창에서 적용하고 유닛 설정을 저장하면 다음 새 게임에 반영됩니다. 인원수는 고정입니다.

## 4. 스토리 모드

### 도입과 층별 진행

금요일 야근 → 토요일 메시지 → 퇴근 권한 거부를 보여 주는 36초 공통 프롤로그 뒤 두 선택지가 나옵니다. 건너뛰기로 바로 선택할 수 있습니다.

- **닥치고 출근하기:** 회사 인원에게 둘러싸여 집중 공격을 받습니다. 상사의 여러 대사가 상단에 나오며, 10초 이상 이어지는 연출 뒤 ‘업무 스트레스로 사망’ 결말로 끝납니다. **이번에는 참지 않기**를 누르면 프롤로그 반복 없이 파괴 경로로 시작합니다.
- **사무실 파괴하기:** 1층부터 전투를 시작합니다.

| 층 | 공간과 진행 |
| --- | --- |
| 1층 | 로비 단말기에서 E로 퇴근 요청 → 거절·전투 시작. 단말기와 지정 보안 대응 인원 3명 처치 |
| 2층 | 일반 사무실. 서버 3개와 지정 방어 담당 3명 처치, 동료 구출은 선택 |
| 3층 | 임원 업무 공간. 지정 임원 6명을 처치하면 진행. 수행원과 새 패턴은 후속 작업 |
| 4층 | 경비견실 → 보디가드실 → 대표실·비서실 |

**1층은 단말기 파괴와 보안 대응 3명, 2층은 서버 3개와 방어 담당 3명, 3층은 지정 임원 6명 완료 시 엘리베이터가 열립니다.** 2층의 다른 직원과 증원 전원 처치는 필수가 아닙니다. 일반 가구 파괴는 이동 조건에 포함하지 않습니다. 다음 층으로 이동하면 이전 층을 제거합니다. 스토리 층은 고정 프리팹 배치이며 Unity에서 눈으로 편집할 수 있습니다.

2층 서버는 어떤 순서로든 파괴할 수 있습니다. 주황색 이름표의 **[방어 담당]** 3명도 처치해야 합니다.

- 업무 배정 서버: 9초마다 증원하며 살아 있는 증원은 최대 2명입니다. 파괴하면 추가 증원이 멈춥니다.
- 보고서 반려 서버: 3초마다 서류 3장을 발사합니다. 파괴하면 해당 공격이 정지합니다.
- 근태 조작 서버: 파괴하면 동료 구역이 열립니다. 동료 3m 이내에서 **E**로 구출합니다.

동료를 구하면 3층 입구에 추가 회복 보급이 나타나며, 대표와 전투 중 체력 70 이하일 때 한 번 체력 30을 지원합니다. 구출하지 않아도 진행할 수 있습니다. 마지막 서버에서 임원회의 결의서를 발견하며 3층으로 올라갈 이유가 드러납니다. 새 게임에서는 구출·보상·목표 상태가 초기화됩니다.

기존 층 프리팹은 유지하며 이번 2층 목표물과 동료 구역은 `Story/OfficeRampageGame.StoryObjectives.cs`의 `SetupStoryFloor()`에서 추가됩니다. 위치 조정도 현재는 이 함수에서 합니다.

대표층에서는 경비견 5마리, 보디가드 5명을 순서대로 처치합니다. 보디가드는 몽둥이 2명·권총 2명·장거리 샷건 1명입니다. 각 구역을 끝내면 경계 벽과 문이 사라져 다음 구역으로 이동하며, 호위를 모두 처치해야 대표를 공격할 수 있습니다.

기본 최대 체력은 100이며 엘리베이터 보상으로 최대 160까지 늘어납니다. 층별 기본 회복 포션은 2개이며 하나당 30을 회복합니다. 정수기는 파괴 시 체력 +5, 전자기기는 폭발 위험이 있는 집기입니다. 가구를 부수지 않아도 층을 진행할 수 있습니다.

스토리 전투 HUD는 무한 모드와 같은 배치입니다. 상단 한 줄에 층·진행 목표·점수·콤보를 표시하고, 좌하단에 체력, 우하단에 현재 무기 아이콘·이름·잔탄을 표시합니다. 1~8 숫자키 전환과 스킬·달리기 아이콘은 유지합니다. 2층 서버·방어 담당·구출 상태는 상단에 합쳐 표시하며, 짧은 이야기 자막은 상단 바로 아래에 나옵니다. 대표전은 작은 체력 타일과 얇은 체력 막대를 사용합니다.

### 엘리베이터 보상

1→2층, 2→3층, 3→4층 이동 중 하나를 선택해야 다음 층으로 진행합니다. 선택 중 전투와 시간이 멈추며, Esc로 일시정지했다 돌아와도 보상 화면을 계속 선택할 수 있습니다.

| 보상 | 효과 | 반복 선택 |
| --- | --- | --- |
| 법인카드 | 권총 200발·샷건 100발·로켓 20발로 보충 | 층마다 가능. 더미와 비밀 무기는 보충하지 않음 |
| 산재 처리 | 최대 체력 +20, 현재 체력 +40 | 최대 체력 상한 160 |
| 퇴근 본능 | 달리기 게이지 회복 속도 +25% | 합산하여 최대 +75%, 달리기 지속시간은 10초 유지 |

보상과 동료 구출 결과는 층을 이동해도 유지됩니다. 새 게임·재게임·무한 모드 시작 시 초기화되며 영구 저장하지 않습니다. 1층 단말기를 먼저 공격하거나 보안 대응 인원을 먼저 처치해도 두 목표를 완료하면 진행할 수 있습니다. 1층의 다른 일반 직원은 필수 처치 대상이 아닙니다.

### 기본 무기와 콤보

| 스토리 키 | 무기 | 특징 |
| --- | --- | --- |
| 1 | 야구빠따 | 피해 40, 무제한, 가로 휘두르기. F: 10초 휠윈드 |
| 2 | 망치 | 피해 90, 무제한. F: 망치를 치켜들고 3초간 낙뢰, 피격 인물 3초 기절 |
| 3 | 권총 | 200발, 피해 32. F: 10초 얼음탄, 피격 유닛 3초 동결 |
| 4 | 기관총 | 빠른 연사, 발당 피해 12, 무제한 탄약 |
| 5 | 미인계 더미 | 층당 3개. 우클릭 궤적 조준 → 좌클릭 투척, 10초 남성 직원 유인 |
| 6 | 화염 샷건 | 100발. 권총과 같은 단일 타격 + 5초간 초당 1 화상 피해 |
| 7 | 로켓런처 | 20발. 직진 화염 꼬리와 폭발, 피해 120 / 반경 4.5m |
| 8 | BFG 18 / ??? | 대표전에서 순서대로 획득하는 일회용 비밀 무기 |

일반 공격으로 가구를 파괴하거나 사람을 처치하면 콤보가 증가합니다. 4초 안에 이어 가지 못하면 초기화됩니다. 방망이·망치·권총은 3콤보 단위로 해당 스킬이 준비되며, 준비 후 10초 안에 해당 무기로 F를 눌러 사용합니다.

휠윈드·낙뢰·얼음탄·지속 화상·소환 지원 등 **스킬 피해는 콤보를 재충전하지 않습니다.** 더미는 여성·대표·경비견에게 통하지 않습니다. 불붙은 가구에는 불꽃·연기가, 사람에게는 당황하는 움직임이 적용됩니다.

권총·샷건·로켓 잔탄은 층 이동 시 유지됩니다. 새 게임과 대표의 로봇 탑승 직후에는 각각 **200 / 100 / 20발**을 보급합니다. 얼음탄도 권총 탄약을 소비합니다.

## 5. 무한 파괴 모드

### 생존 규칙과 보급

64m 전장에서 적과 가구를 상대하며 오래 버티는 모드입니다. 층 이동이나 대표전은 없고, 제한 시간 없이 생존 기록을 쌓습니다.

- 기본 무기는 **광선검**입니다. 피해 40, 가로 베기, 3콤보 F 휠윈드를 사용하며 탄약은 무제한입니다.
- 바닥 장비 **2.5m 이내에서 E**를 누르면 즉시 장착합니다. 인벤토리 보관과 숫자키 교체는 없습니다.
- 탄약·일회용 사용량이 소진되면 기본 광선검으로 복귀합니다. 새 무기를 주우면 해당 무기의 수량이 채워집니다.
- 미인계 더미는 무한 모드에서 생성·획득하지 않습니다. 사용 가능한 바닥 무기는 **21종**, 기본 광선검은 별도입니다.
- 갑옷은 내구도 +60, 최대 100이며 피해의 70%를 내구도만큼 흡수합니다. 회복 보급은 체력 +30입니다.
- 적은 시작 5초 뒤부터 한 번에 2명씩 생성됩니다. 시간이 지나면 생성 간격과 체력이 강화되며 동시 적 상한은 80명입니다.
- 일반 무기는 **3초마다** 별도로 보급합니다. 지진 유발기와 운석 소환기는 각각 별도의 **30초 주기**로 생성됩니다. 플레이어 주변 빈 위치를 우선 사용하고 목록을 섞어 반복을 줄입니다. BFG·위성 호출기는 30초 이후 보급 목록에서 선택됩니다.
- 회복·갑옷 보급은 별도로 8초 주기이며, 14% 확률로 피해 2배 아이템이 등장합니다. 바닥 보급 상한은 18개이며 무기 보급과 가까운 장비를 보호합니다.
- 가구는 재생성되며, 플레이어 근처나 충돌하는 자리는 피합니다. 전자기기 폭발은 주변 적을 공격하는 함정으로 사용할 수 있습니다.

기본 무기 7종은 야구빠따·망치·권총·기관총·화염 샷건·로켓런처·BFG 18입니다. 여기에 아래 특수 무기 14종을 더해 총 21종입니다.

| 교통사고 | 1 | 10초 동안 다양한 차량 소환, 커진 차체와 충돌 범위 |

| 전투기 폭격 지원 | 1 | 전투기 3대가 나란히 5초간 통과하며 폭격, 종료 시 적·가구 전멸 |

무한 모드 BFG 18은 반경 24m 광역 폭발이며 스토리의 대표·로봇 전환을 호출하지 않습니다. 위성 호출기는 적·가구·보급을 정리하고 빈 전장을 3초 유지한 뒤 적 24명·가구·초기 장비를 보충합니다. 체력·갑옷·기록은 이어집니다.

공중 지원 중에는 카메라 시야가 넓어집니다. 드론은 3대 한 편대만 유지하며 재사용하면 지원 시간을 갱신합니다. 전투기·블랙홀 진행 중에는 새 적·가구·보급 생성을 잠시 멈추고 종료 후 재개합니다. 진행 중인 새 궁극기와 충돌하는 BFG·위성·탑승·다른 새 궁극기는 중복 발동하지 않으며 이 경우 사용량도 소비하지 않습니다. 지원 공격은 플레이어에게 피해를 주거나 콤보를 충전하지 않습니다.

### 헐크버스터 조작

조종기를 E로 주운 뒤 왼쪽 클릭하면 탑승합니다. 탑승 시간은 20초이며 일시정지하면 함께 멈춥니다.

| 항목 | 동작 |
| --- | --- |
| 왼쪽 클릭 | 왼손 초록색·오른손 빨간색 광선검 동시 가로 베기 |
| 쌍검 판정 | 피해 120, 범위 7m, 간격 0.75초. 두 검이 중복 피해를 주지는 않음 |
| 오른쪽 클릭 | 전방 대쉬, 재사용 대기시간 3초 |
| 대쉬 | 0.35초 동안 최대 10.5m 이동, 벽·장애물에 닿으면 정지 |
| 충돌 효과 | 대상마다 대쉬당 1회 피해 120, 적 1.5초 기절 |
| 방어 | 받는 피해 50% 감소 후 갑옷 흡수 적용 |
| 보급 | 회복·갑옷·피해 2배 획득 가능, 무기 교체는 탑승 종료 후 가능 |
| 종료 | 원래 캐릭터 크기·카메라 복구, 기본 광선검 장착 |

대쉬는 우클릭할 때 시도하며 작은 아이콘과 숫자로 대기시간을 보여줍니다. 예전 오른쪽 광선 발사는 대쉬로 교체했습니다. 탑승 공격은 콤보를 충전하지 않습니다. **스토리 대표의 로봇과 플레이어 탑승 로봇은 서로 다른 전투 동작을 사용합니다.**

### 배경 전환

처음에는 광장에서 시작합니다. 첫 전환은 사막, 이후에는 무인도와 사막이 번갈아 나옵니다. 사막은 모래언덕·선인장·바위, 무인도는 바다·해변·야자수·파도로 구성합니다.

- 생존 시간 **5분·10분·15분…**마다 전환합니다.
- 슈퍼 무기 사용시에도 전환 됩니다.

무기 사용으로 배경이 바뀌어도 다음 5분 주기는 유지합니다. 배경 전환 자체는 체력·기록·장비를 초기화하지 않습니다. 전장의 이동 경계는 유지되며 바다와 먼 모래언덕으로는 나갈 수 없습니다. 새 게임은 다시 광장에서 시작합니다. 이 규칙은 무한 모드에만 적용합니다.

### HUD와 피해 2배 표시

상단 정보는 **생존 시간 | 처치 | 점수 | 콤보 | 적 수/상한 | 최고 기록**을 얇은 한 줄 바에 표시합니다. 숫자가 길어지면 글자 크기를 자동 조절합니다.

하단에는 스킬·지원·달리기 아이콘과 남은 시간, 우측에는 짧은 획득 알림과 대상 상태를 표시합니다. 긴 전투 안내문 대신 아이콘과 숫자를 사용합니다. 도입 대사·메뉴·엔딩·랭킹 설명은 유지합니다.

보라색 **피해 2배** 아이템은 20초 동안 적·가구에 주는 피해를 2배로 만듭니다. 획득 고리·효과음, 발밑 보라색 오라, 무기창 위 **×2 / 남은 초 / 게이지**로 표시합니다. 마지막 3초에는 색이 바뀌며, 재획득은 시간을 갱신하고 4배로 중첩하지 않습니다.

### 결과와 Top 10

체력이 0이 되면 생존 시간·처치 수·게임 점수를 표시합니다. 이름을 입력하고 **기록 등록**하면 로컬 Top 10에 저장합니다. 이름은 한글을 포함해 최대 24자이며, 등록하지 않고 재도전할 수도 있습니다.

**종합점수 = 게임 점수 + 생존 초 × 10 + 처치 수 × 100**

동점이면 생존 시간 → 처치 수 → 게임 점수 → 먼저 등록한 기록 순으로 정렬합니다. 같은 이름으로 여러 판을 등록할 수 있지만 여러 판을 합산하지는 않습니다. **무한 파괴 → Top 10 랭킹**에서 다시 확인할 수 있습니다. 온라인 공용 랭킹이 아니라 실행 환경의 로컬 저장 기록입니다.

## 7. Web 빌드와 한글 폰트

게임은 운영체제 설치 폰트 대신 프로젝트에 포함된 `Assets/Fonts/NotoSansKR-VariableFont_wght.ttf`를 사용합니다. `OfficeGameFont`가 Resources의 `GameFont.asset`을 읽고, 이 자산이 원본 TTF를 직접 참조하여 빌드에 포함합니다. 원본 파일의 위치와 GUID는 유지했습니다.

- IMGUI 메뉴·버튼·HUD·이름 입력·랭킹은 같은 한글 폰트를 사용합니다.
- TextMesh는 `font`와 `MeshRenderer.sharedMaterial`을 함께 지정합니다.
- 이름 입력의 기존 TextField·포커스·IME 조합 처리는 유지합니다.
- 폰트 참조·재질·샘플 글리프 실패는 `[OfficeFont]` 오류로 보고합니다.
- TTF는 **Dynamic / Include Font Data**를 유지하고, `GameFont.asset`의 Font 참조가 비어 있지 않은지 확인하세요.

**검증 범위:** 원본 가변 폰트의 Editor 임포트·한글/영문/숫자 글리프·메뉴/입력창 표시와 문자열 반영 검사는 통과했습니다. 별도 검증 프로젝트에서 실제 Web 개발 빌드도 오류 0개로 성공했습니다. 다만 브라우저 접근 제한으로 **실제 Web 화면, 브라우저 런타임 오류 및 키보드 한글 조합 입력은 아직 미검증**입니다. 빌드 성공과 브라우저 동작 검증은 구분합니다.

원본 프로젝트에서 Web으로 다시 빌드한 뒤 HTTP(S)로 실행하고 메뉴·이름표·숫자·이름 입력을 확인하세요. 기존 배포 캐시가 남아 있다면 새 빌드 주소나 캐시 갱신 후 확인합니다. 현재 가변 폰트의 기본 굵기는 100이며 얇게 보일 수 있습니다. 고정 굵기 TTF가 필요한 경우의 변환법과 전체 확인 항목은 [Web 폰트 수정 보고서](Docs/WEB_FONT_FIX.md)에 정리했습니다.
