# 무한 파괴 모드

첫 메뉴의 **스토리 모드**는 기존 4층 게임입니다. **무한 파괴 → 생존 시작**은 별도 3D 전장에서 끝없이 버티는 모드입니다. 제한 시간과 층 이동, 대표 보스 진행은 없습니다. 체력이 0이 되면 생존 시간·처치 수·점수가 표시되며 다시 도전하거나 첫 메뉴로 나갈 수 있습니다.

## 장비와 조작

- 시작 무기: 광선검(무한 모드 전용). WASD 이동, 마우스 조준, 왼쪽 클릭 공격, Space 점프, Shift 달리기, Esc 일시정지입니다.
- 군중을 보기 쉽게 카메라를 뒤로 뺐습니다. 적 이름표는 화면을 덮지 않도록 숨기고, 전방의 가까운 적 한 명의 이름/체력을 HUD에 표시합니다.
- 바닥 장비 2.5m 이내에서 **E**를 눌러 줍습니다. 무기는 즉시 현재 장비를 대체합니다. 인벤토리 보관은 없으며 이전 무기로 돌아가려면 해당 무기를 다시 주워야 합니다. 숫자키 1~8로는 교체할 수 없습니다.
- 갑옷은 내구도 60을 더하며 최대 100입니다. 공격 피해의 70%를 남은 내구도만큼 흡수합니다. 회복 보급은 체력 30을 회복합니다. 이미 가득 찬 보급은 소비하지 않습니다.
- 무기를 새로 주우면 해당 무기의 탄약/사용 횟수가 채워집니다. 장비를 바꾸면 이전 장비의 준비된 스킬과 더미는 초기화됩니다.
- 탄약/사용 횟수가 소진되면 기본 광선검으로 자동 복귀합니다. 피해40/공격 간격0.32초/사거리2.7m 및 3콤보 F 휠윈드는 방망이와 같은 전투 처리를 사용합니다. E로 새 무기를 다시 주울 수 있습니다. 바닥의 야구빠따는 별도 무기로 유지됩니다.
- 일반 공격으로 사람을 처치해도 4초 콤보에 포함됩니다. 방망이·망치·권총의 일반 공격으로 3콤보를 달성하면 해당 스킬이 준비됩니다. 휠윈드·낙뢰·얼음 총알·악마·자동차 등 스킬 피해로 처치할 때는 콤보가 증가하지 않습니다.
- 보라색 피해 2배 보급은 20초 동안 적·가구에 주는 피해를 2배로 만듭니다. 다시 주우면 20초로 갱신되며 4배로 중첩되지는 않습니다. 일시정지/위성 연출 중에는 시간이 줄지 않습니다.
- 야구빠따·망치·권총의 기존 콤보 스킬은 F로 사용합니다. 더미는 오른쪽 클릭 조준 후 왼쪽 클릭으로 투척합니다.

| 무기 | 특징 / 새로 주울 때 사용량 |
| --- | --- |
| 광선검(기본) | 무제한, 피해40, 3콤보 F 휠윈드. 탄약 소진 후 복귀 무기 |
| 야구빠따 | 근접, 콤보 휠윈드 |
| 망치 | 강한 근접, 콤보 번개 소환 |
| 권총 | 200발, 콤보 얼음 총알 |
| 기관총 | 빠른 연사, 무제한 탄약 |
| 미인계 더미 | 3회, 기존 남성 유인 규칙 |
| 화염 샷건 | 100발, 화상 |
| 로켓런처 | 20발, 폭발 |
| BFG 18 | 1회, 반경 24m 광역 폭발; 스토리 지형/보스 연출로 전환하지 않음 |
| 번개 스테이플러 | 40회, 전방 최대 5명 연쇄 번개와 짧은 기절 |
| 레이저 프린터 | 40회, 45m 관통 광선, 벽에서 멈춤 |

| 초강력 청소기 | 40회, 전방 적 끌어오기와 가구 파괴 |
| 퇴근 종 | 40회, 반경 11m 충격파와 기절 |
| 위성 호출기 | 1회, 보스전과 같은 3단계 줌아웃·위성 5기·지구 분리 연출. 적/가구/보급을 지운 뒤 3초 후 재생성하고 생존 계속 |
| 지옥문 | 1회, 악마가 10초 동안 적을 추적하며 0.5초마다 피해45 공격 |
| 교통사고 | 1회, 10초 동안 0.75초마다 색/형태/진입 방향이 다른 차량 소환. 적 피해90/가구 피해120, 차량당 대상별 1회. 플레이어에게 피해 없음. 차량 외형 2배, 상자형 충돌 판정도 함께 확대 |
| 헐크버스터 | 1회, 20초 탑승. 왼쪽 클릭 거대 검(피해120/7m/0.75초), 오른쪽 클릭 광선(피해90/50m/0.7초). 받는 피해50% 감소. 종료 후 광선검 복귀 |

헐크버스터는 E로 조종기를 주운 뒤 왼쪽 클릭으로 탑승합니다. 사람의 약3배 높이 모델과 큰 캐릭터 충돌체, 걷는 다리·거대 광선검·탑승자 모델을 사용합니다. 카메라도 탑승에 맞게 멀어집니다. 탑승 중 회복/갑옷/피해2배 보급은 주울 수 있지만 다른 무기 교체는 종료 후 가능합니다. 탑승 공격은 콤보를 충전하지 않습니다. 일시정지하면 탑승 시간도 멈추고, 종료·재시작 시 원래 캐릭터 크기로 복구됩니다.

## 지속 전투와 성능 제한

- 시작 5초 뒤 한 번에 적 2명이 등장하며 생성 간격이 점차 1.5초에서 최소 0.4초까지 줄어듭니다. 적 체력도 증가합니다. 동시에 살아 있는 적은 최대 80명이며 처치하면 빈자리를 계속 보충합니다.
- 8초마다 무기/갑옷/회복 보급이 순환 등장합니다. 각 주기에는 14% 확률로 피해 2배 보급이 대신 등장합니다. 지옥문·교통사고·헐크버스터는 초기 장비에도 한 개씩 배치됩니다. BFG와 위성 호출기는 90초 이후 등장합니다. 바닥 보급품은 최대 18개이며 오래된 보급부터 제거합니다. 적 4명마다 회복 보급, 12명마다 갑옷 보급이 추가됩니다.
- 전장의 가구 36개는 10초마다 재생성 여부를 확인합니다. 플레이어 6m 이내이거나 다른 충돌체가 있는 자리는 비워 둡니다. 전자기기는 주변 적에게 폭발 피해를 줍니다.
- 위성 연출 동안 전투와 생성이 정지합니다. 전장을 비운 다음 3초 동안 적/가구/보급이 없는 상태를 유지합니다. 이후 적 24명과 초기 장비, 가구를 보충합니다(플레이어와 겹치는 가구는 나중에 재생성). 체력·갑옷·점수·생존 시간은 이어집니다.
- 자동차는 동시에 최대8대, 각3초 수명이며 지원10초가 끝나면 남은 차량도 제거합니다. 악마는 한 마리만 유지하고 재사용 시 갱신합니다.
- 사망한 적과 경고 표시는 제거합니다. 기존 일반 효과 160개/파편 70개 제한도 사용합니다. 이 수치는 객체 개수 제한이며 특정 PC의 프레임률 보장을 뜻하지 않습니다.
- 개인 최고 생존 시간과 최고 점수는 PlayerPrefs의 `OfficeRampage.Endless.BestTime`, `OfficeRampage.Endless.BestScore`에 저장됩니다. 생존 최고 기록은 HUD에 표시됩니다. 온라인 순위표는 없습니다.

## 작은 아이콘 HUD

- 긴 스킬/버프 알림은 하단 아이콘과 숫자(남은 초)로 바뀌었습니다. 준비 상태는 청록색 `F`, 사용 중은 주황색이며 작은 막대도 줄어듭니다.
- 소용돌이/번개/눈꽃: 휠윈드/토르/얼음탄. 하트: 더미 유인. 곱하기/악마 얼굴/자동차/로봇 얼굴: 피해 2배/지옥문 지원/교통사고/헐크버스터 남은 시간.
- 우측 작은 `E` 아이콘은 근처 보급 줍기입니다. 획득/회복/탄약 알림도 우측에만 표시합니다. 전방 적 정보는 우측 상단 해골 아이콘과 체력 숫자로 줄였습니다.
- 배치/색상/도형은 `Scripts/UI/OfficeRampageGame.CompactHUD.cs`, 무한 모드의 나머지 HUD는 `OfficeRampageGame.EndlessHUD.cs`에서 조정합니다.
- 이번 변경은 HUD 표시만 다룹니다. 보급 생성 주기, 발사 모션, 악마 크기/소환 연출, 5분 배경 전환은 변경하지 않았습니다.

## 로컬 Top 10 랭킹

- 사망 시 생존 시간(초 단위), 처치 수, 게임 점수를 확정하고 이름 입력 화면을 표시합니다. 한글 이름은 기존 유닛 설정과 같은 IME 입력기를 사용하며 최대 24자입니다.
- **기록 등록**을 눌러 저장합니다. 빈 이름은 등록할 수 없고 한 판을 중복 등록할 수 없습니다. 등록 없이 재도전/메뉴 이동도 가능합니다.
- 종합점수 = **게임 점수 + 생존 초 × 10 + 처치 수 × 100**. 높은 순으로 10개만 보관합니다. 동점이면 생존 시간, 처치 수, 게임 점수가 높은 기록, 이후 먼저 등록한 기록 순입니다.
- 각 판별 기록입니다. 같은 이름으로 여러 판 등록할 수 있으며 여러 판을 합산하지 않습니다. 10위 미만 기록은 보관하지 않습니다.
- **무한 파괴 → Top 10 랭킹**에서 순위, 이름, 시간, 처치 수, 게임 점수, 종합점수를 확인합니다.
- PlayerPrefs 키: `OfficeRampage.Endless.Leaderboard.v1`(JSON), `OfficeRampage.Endless.LastPlayerName`(최근 이름). 기존 개인 최고 기록 키는 유지합니다. 이 PC의 로컬 기록이며 온라인 순위표는 아닙니다. 잘못된 JSON은 빈 목록으로 복구합니다.

## 유지보수 위치

모드 전용 코드는 `Assets/OfficeRampage/Scripts/Endless/`에 모았습니다.

- `OfficeRampageGame.Endless.cs`: 전장 배치, 생성 간격/상한, 난이도, 기록.
- `OfficeRampageGame.EndlessLoot.cs`: 줍기, 탄약/갑옷, 장비 외형.
- `OfficeRampageGame.EndlessWeapons.cs`: 새 무기 피해/효과/사거리.
- `OfficeRampageGame.EndlessExtras.cs`: 처치 콤보·기본 무기 복귀·2배 피해·악마.
- `OfficeRampageGame.EndlessSaber.cs`: 기본 광선검 외형/공유 광선 재질.
- `OfficeRampageGame.EndlessMech.cs`: 탑승/공격/만료/충돌체 복구.
- `OfficeRampageGame.EndlessMechModel.cs`: 탑승 로봇 외형.
- `OfficeRampageGame.EndlessTraffic.cs`: 자동차 생성/이동/피해/수명.
- `OfficeRampageGame.EndlessOrbital.cs`: 위성 연출·전장 정리·3초 재생성.
- `OfficeRampageGame.EndlessHUD.cs`: HUD, 시작 안내.
- `OfficeRampageGame.EndlessRanking.cs`: 종료 후 이름 입력, 결과 화면, Top 10 메뉴.
- `OfficeEndlessLeaderboard.cs`: 점수 계산, 정렬, 이름 정리, 로컬 저장.
- `OfficeDefender.Endless.cs`: 무한 모드 추적 이동.
- `OfficeEndlessPickup.cs`: 바닥 장비 데이터.

현재 무한 전장은 런타임에 생성됩니다. 기존 스토리 층 프리팹은 그대로 유지하며, 무한 전장 배치는 `BuildEndlessArena`에서 수정합니다. 외부 에셋이나 새 패키지는 추가하지 않았습니다.
