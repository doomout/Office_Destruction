# 층 디자인을 눈으로 편집하기

이제 정상 게임은 **Floor1~4.prefab에 저장된 실제 가구·벽·재질과 시작 위치**를 사용합니다. JSON을 고치거나 Play 중에 배치를 수정할 필요가 없습니다.

## 열기와 저장

1. Unity에서 Play를 종료합니다.
2. 상단 **Tools → Office Rampage → Floors → 1층 로비 편집**을 선택합니다. 2·3·4층도 같은 메뉴에 있습니다.
3. Prefab Mode에서 해당 층 전체가 열립니다. 처음에는 천장·외벽을 편집 화면에서만 가립니다. `천장·외벽 표시 전환` 메뉴로 다시 표시할 수 있습니다. 이 숨김은 게임에 저장되지 않습니다.
4. Hierarchy에서 물체를 선택하고 Scene 창 위에 마우스를 놓은 뒤 **F**로 해당 물체를 확대합니다.
5. **W 이동 / E 회전 / R 크기**, **Ctrl+D 복제**, Delete 삭제를 사용합니다. Scene 창에서 오른쪽 마우스를 누른 채 WASD로 돌아볼 수 있습니다.
6. **Ctrl+S**로 저장합니다. Prefab Mode의 왼쪽 위 뒤로가기 화살표로 나옵니다.
7. 원래 `OfficeRampage.unity` 씬에서 Play → 새 게임으로 확인합니다. 실행 중인 층에는 편집 내용을 소급 적용하지 않으며 다시 생성될 때 읽습니다.

Project 창에서 아래 파일을 더블클릭해도 됩니다.

| 파일 | 내용 |
| --- | --- |
| `Assets/OfficeRampage/Resources/OfficeFloors/Floor1.prefab` | 로비 |
| `Assets/OfficeRampage/Resources/OfficeFloors/Floor2.prefab` | 사무실 |
| `Assets/OfficeRampage/Resources/OfficeFloors/Floor3.prefab` | 임원층 |
| `Assets/OfficeRampage/Resources/OfficeFloors/Floor4.prefab` | 대표층 |

## 어떤 것을 선택할까?

- **가구 · 이동 회전 크기 편집**: 책상/컴퓨터/수납장 등을 통째로 이동·회전·확대하거나 복제합니다. 하위 모델과 재질도 저장되어 게임에 사용됩니다. 파괴 동작은 가구 루트의 OfficeProp 컴포넌트가 담당하므로 이 컴포넌트는 유지하세요. 기존 가구를 복제하면 파괴 기능도 유지됩니다.
- **파티션 · 통로를 막지 않도록 편집**: 벽을 이동하거나 복제·삭제합니다. 실제 Collider의 모양으로 이동 장애물을 읽으므로 길찾기도 바뀝니다. 회전한 벽은 안전하게 감싸는 직사각형 범위로 길찾기에 반영됩니다. 통로에 여유를 주세요.
- **직원 시작점 · 개수 유지**: 사람/경비견 모양의 미리보기를 담은 시작점 루트를 움직입니다. 루트의 회전도 실제 적 시작 방향에 반영됩니다. 미리보기 하위 모델을 바꾸는 것은 실제 직원 모델 교체와 다릅니다. 실제 이름·성별·캐릭터는 기존 유닛 설정과 카탈로그에서 결정합니다.
- **회복 포션**: 병 루트를 이동합니다. 게임에서도 그 위치에서 회복 아이템이 됩니다.
- **엘리베이터 · 문과 통째로 이동**: 문과 캐빈을 함께 움직입니다. 벽의 출입구와 정렬하고, 밖으로 이어지는 바닥도 끊기지 않게 조정하세요. 바닥·벽이 자동으로 늘어나지는 않습니다.
- **플레이어 시작점**: 시작 위치와 바라보는 방향입니다. 캡슐은 편집용이며 실제 게임에는 표시하지 않습니다.
- **대표 시작점 / 비서 시작점 / 보디가드 시작점**: 대표층의 인물 위치입니다. 인물 미리보기보다 시작점 루트를 움직이세요.
- **비서 출입 동선점**: 비서가 방에서 나오는 문 앞 위치입니다. 비서실 문을 옮기면 이 점도 옮깁니다. 출입 동선점에는 Transform 이동 핸들이 표시됩니다.
- **Office architecture**: 천장·외벽·창문입니다. 재질은 Renderer에서 바꿀 수 있으며 `Art/FloorMaterials`에 저장됩니다.

## 진행을 유지하는 편집

- 직원/경비견 시작점은 층별 **10 / 26 / 6 / 5개**, 보디가드는 **5개**를 유지합니다. 고정 인원과 연결되어 있으므로 시작점 삭제·추가가 아니라 위치를 편집하세요.
- 4층의 경비견 → 보디가드 → 대표 구역 순서와 두 문은 유지합니다. 두 문은 앞뒤 순서를 유지한 채 배치하고, 구역 사이를 돌아서 우회할 틈을 만들지 마세요. 두 구역의 AI 이동 제한은 문의 앞뒤 z 위치를 기준으로 합니다.
- 층 루트는 원점·회전 0·크기 1을 유지합니다. 입구는 z=0, 출구는 양의 z 방향입니다. 외곽 크기를 바꾸는 경우 Floor와 외벽·천장·캐빈도 함께 조정해야 합니다. 일반 가구 배치 편집에는 필요 없습니다.
- 프리팹 루트를 선택하고 Inspector의 **배치 / 길찾기 검사**를 누르세요. 이동/회전/스케일과 충돌은 이후 실제 Play에서도 확인합니다. 이 검사는 전투 난이도나 문 우회 가능성까지 자동 보장하지 않습니다.
- 시간 제한 없음, 직원 전원 처치, 가구 폭발, 보스/비서/로봇/엔딩 규칙은 그대로입니다.

## 보관된 JSON과 복구

`Resources/OfficeLayouts/floor1~4.json`은 이전 배치와 복구용으로 보관합니다. 정상 게임은 `Resources/OfficeFloors/Floor1~4.prefab`을 우선 읽습니다. JSON만 수정하면 프리팹이 있는 게임에는 반영되지 않습니다.

기존 게임 씬을 새 층 프리팹으로 바꾸거나 덮어쓸 필요가 없습니다. 프리팹과 `.meta` 파일을 함께 백업하고, Unity 안에서 이름 변경·이동하세요. 현재 Resources 경로의 Floor1~4 파일명은 로딩에 사용하므로 유지해야 합니다.


## 2026-11-16 지구 분리 피니시와 배치/밸런스 보정

- 대표의 분노는 50%, 비서의 BFG 18 전달은 20%입니다. 로봇 20%에서 받는 빨간 버튼과 구분합니다.
- 마지막 위성 공격은 우주 화면에서 지구가 세로로 갈라지고 두 반구와 주황색 단면이 드러나는 연출입니다. 기존 마지막 2배 핵폭발을 대체하며 BFG 18의 건물 붕괴/버섯구름은 유지합니다. 이후 로봇 분리·대표 탈출·엔딩으로 이어집니다.
- 대표층의 각 호위 전투가 끝나면 해당 가로 구역 벽과 문이 사라집니다. 경비견 전멸 뒤 보디가드는 첫 방으로도 이동하며, 대표전에서는 이전 구역까지 이동합니다. 벽 제거 후 길찾기를 새로 만듭니다.
- 3층 Floor3.prefab의 파티션만 제거하고 책상·직원·배경은 유지합니다. 로비 직원은 100 HP이며 무기 수치는 유지합니다. 권총 4회, 방망이 3회, 망치 2회가 필요하며 로켓 직격은 여전히 강력합니다.
- 관련 코드: Effects/OfficeEarthSplit.cs, Story/OfficeRampageGame.EarthFinale.cs, World/OfficeRampageGame.StageBarriers.cs. 프리팹을 편집할 때 대표층 구역 경계 벽은 문의 z 위치와 일치하도록 유지합니다.
