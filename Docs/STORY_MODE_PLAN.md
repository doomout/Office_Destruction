# 스토리 모드 확장 기획

기획명: **사무실 파괴: 퇴근 승인 바랍니다**  
작성일: 2026-11-24  
상태: 1~3차 구현 · 새 퇴근 엔딩은 후속 작업

무한 파괴 모드는 마음껏 부수며 스트레스를 푸는 모드로 유지한다. 스토리 모드는 주인공이 왜 화가 났는지, 누구에게 책임이 있는지, 왜 위층으로 올라가는지를 플레이로 전달한다. 기존 4개 층과 대표전 연출을 활용하고, 먼저 맵 규모를 늘리기보다 사건과 목표를 연결한다.

목표 플레이 시간은 15~20분으로 잡되 실제 테스트 후 조정한다. 이 문서는 앞으로의 개발 기준이며, 현재 출시 기능 설명은 [README](../README.md)를 따른다.

## 현재 구현과 변경 범위

| 구분 | 현재 기준 | 확장 방향 |
| --- | --- | --- |
| 도입 | 36초 공통 프롤로그, 출근 또는 파괴 선택, 출근 엔딩에서 바로 재도전 | 1차 구현 완료 |
| 층 구성 | 로비 → 일반 사무실 → 임원층 → 대표실 | 기존 공간에 사건과 목표 추가 |
| 이동 조건 | 1층 단말기·보안 대응, 2층 서버·방어 담당, 3층 임원·지원 인원 세 전투 | 3차까지 적용 |
| 제한 시간 | 없음 | 유지 |
| 대표전 | 경비견 → 경비 → 대표, 분노와 BFG18, 로봇 및 위성 연출 | 기존 전투에 대사와 사건의 이유 연결 |
| 결말 | 대표의 무작위 대사, 확인과 재게임 | 퇴근 장면과 구출 여부에 따른 짧은 변화 추가 |
| 무한 모드 | 별도 생존 모드 | 이번 스토리 확장으로 규칙을 바꾸지 않음 |

1차에서 2층에 한해 서버 3개와 지정 방어 담당 3명 완료 조건을 적용했다. 2차에서 1층은 단말기와 보안 대응 3명, 3층은 지정 임원 6명으로 연결했다. 구석에 남은 적을 찾는 시간을 줄이되, 필수 전투를 건너뛰지 않도록 층별 완료 조건을 명시하고 구현한다. 기존 무기·콤보·탄약·입력·폰트와 사용자 이름 설정은 별도 요청 없이는 유지한다.

## 공통 프롤로그

30~45초 안에 상황을 전달하며 건너뛰기를 제공한다. 두 선택지 모두 같은 프롤로그를 본다.

1. 금요일 밤, 불 꺼진 사무실에서 주인공만 일한다.
2. 토요일 아침 휴대전화에 메시지가 연이어 온다.
   - “오늘 잠깐만 나와줄 수 있지?”
   - “주말 근무 신청은 하지 말고. 승인하기 번거로워.”
   - “그리고 어제 올린 보고서, 처음부터 다시 하자.”
3. 출입구에 사원증을 찍자 안내가 나온다. “출근이 확인되었습니다. 퇴근 권한은 없습니다.”
4. 주인공이 사원증과 방망이를 바라본 뒤 선택지가 나온다.

| 선택 | 진행 |
| --- | --- |
| 닥치고 출근하기 | 기존 상사들의 집중 공격 연출과 “업무 스트레스로 사망”. 이후 “이번에는 참지 않기”로 파괴 경로에 바로 진입 |
| 사무실 파괴하기 | “좋아. 승인권자 나오라고 해.” 이후 로비에서 시작 |

다시 시도할 때 프롤로그를 강제로 반복하지 않는다.

## 1층 로비

**출근은 자유, 퇴근은 승인**

목표는 출구가 잠긴 이유를 확인하고 엘리베이터를 작동시키는 것이다. 벽에는 “직원이 행복한 회사” 포스터가 붙어 있고, 방송은 “직원의 자유로운 퇴근을 위해 사전 승인을 의무화했습니다.”라고 안내한다.

퇴근 요청을 하면 단말기가 거절하고 주인공을 “근무 태도 이상자”로 등록한다. 첫 전투가 시작되며 이동, 기본 공격, 콤보 스킬을 짧게 익힌다. 지정 전투를 끝내고 보안 단말기를 파괴하면 엘리베이터가 열린다.

단말기의 마지막 안내는 “퇴근 승인 담당: 2층 운영팀”. 다음 층으로 갈 이유를 바로 알려준다.

완료 조건안: 첫 지정 전투 완료 + 보안 단말기 파괴. 단말기 선파괴 등 순서가 바뀌어도 진행이 막히지 않게 한다.

## 2층 일반 사무실

**야근은 시스템이 시켰습니다**

필수 목표는 서버 3개 파괴이며 순서는 자유다. 동료 구출은 선택 목표다.

| 목표 | 회사의 부조리 | 파괴 후 변화 |
| --- | --- | --- |
| 업무 배정 서버 | 끝낸 일을 다시 배정 | 해당 구역 증원 중단 |
| 보고서 반려 서버 | 보고서를 자동으로 반려 | 서류 공격 지원 장치 정지 |
| 근태 조작 서버 | 야근을 자기계발 시간으로 기록 | 갇힌 동료 구역 개방 |

동료는 “나도 나가고 싶은데… 퇴근 버튼이 회색이야.”라고 말한다. 구출하면 다음 층에서 회복 보급을 받고 최종전에서 짧은 지원을 받는다. 1차에서는 3층 입구의 회복 보급과 대표전에서 체력 70 이하일 때 한 번 체력 30 지원으로 적용했다.

마지막 서버에서 “주말 출근 자동 승인 — 임원회의 결의” 문서를 발견한다. 시스템 뒤에 결정권자가 있다는 사실을 알고 3층으로 올라간다.

완료 조건안: 서버 3개 파괴 + 지정 방어 전투 완료. 일반 적 전원 처치를 추가 조건으로 중복 요구하지 않는다. 구출하지 않아도 다음 층에 갈 수 있다.

## 3층 임원층

**제 담당은 아닙니다**

임원은 수만 늘리지 않고 서로 다른 공격과 공략법을 가진 중간 보스로 구성한다. 기존에 없앤 파티션 미로는 되살리지 않는다.

| 유형 | 대사 | 전투 패턴 |
| --- | --- | --- |
| 보고서 집착형 | “양식이 바뀌었네. 다시 해.” | 바닥에 범위를 예고한 후 서류 일제 사격 |
| 정신력 강조형 | “힘들다는 건 마음가짐 문제야.” | 퍼져 나가는 음파, 공격 후 반격 기회 제공 |
| 책임 회피형 | “내가 결정한 건 아니고…” | 결재 담당을 처치하면 보호막 해제 |

패배 대사는 “이건 상무님 지시야.” → “전무님이 추진한 건데?” → “대표님 뜻이지, 내 뜻은 아니야.”로 책임을 위로 넘긴다. 기존 임원 순서대로 두 명씩 보고서·정신력·책임 회피 패턴을 배정한다.

마지막 문서에는 “주말 근무 수당 지급 불가. 단, 임원 골프 일정은 근무로 인정.”이 적혀 있다. 대표실 접근을 위한 결재 권한을 얻고, 이 권한이 최종 위성 공격에도 연결되도록 한다.

완료 조건안: 임원과 지원 인원 여섯 명씩 세 전투 완료, 대표실 접근 권한 획득.

## 4층 대표실

**협상의 여지가 있습니다**

경비견 → 보디가드 → 대표 순서는 유지한다. 구간마다 회유가 점점 노골적으로 변한다.

| 구간 | 대사 예시 |
| --- | --- |
| 경비견 | “우리 회사는 가족 같은 분위기라니까?” |
| 보디가드 | “일단 진정하고, 방망이부터 내려놓게.” |
| 대표 대면 | “그래, 원하는 게 뭔가? 피자 파티?” |

대표전의 기존 장면에 다음 이유를 연결한다. 전투 수치와 발동 시점을 기획 대사 때문에 임의로 바꾸지 않는다.

| 기존 장면 | 이야기에서의 역할 |
| --- | --- |
| 인간 대표 체력 50% 이하 분노 | 회유가 통하지 않자 권위를 잃고 폭발 |
| 인간 대표 체력 20% 이하 비서의 BFG18 제공 | 비서 역시 퇴근하지 못하고 있었음이 드러남 |
| BFG18과 건물 붕괴 | 회사의 겉모습이 무너지고 대표의 본색 노출 |
| 우주에서 로봇 투하 | 직원 복지 예산으로 만든 “경영 효율화 장비” 공개 |
| 최종 위성 공격 | 임원층에서 얻은 권한으로 대표의 비밀 장비를 역이용 |

비서 대사: “저도… 이번 주에 집에 못 갔어요.” / “이거 쓰세요. 퇴근 처리는 제가 할게요.”

분노는 50%, BFG18은 20%라는 구분을 유지한다. 위성 무기의 획득과 사용 조건도 기존 로봇 전투 조건을 유지한다.

## 파괴 대상과 층 사이 보상

파괴에는 전투와 진행에 도움이 되는 차이를 준다. 모든 가구를 부수도록 강제하지 않는다.

| 대상 | 역할 |
| --- | --- |
| 감시 카메라와 보안 장치 | 연결된 증원 중단 |
| 전자제품 | 폭발 함정으로 적에게 피해 |
| 동료가 갇힌 구역의 장치 | 선택 구출 경로 개방 |
| 일반 가구 | 파괴 쾌감과 엄폐 활용, 엄폐 판정은 별도 구현 필요 |

엘리베이터에서는 아래 3개 중 하나를 골라 이번 플레이 동안 적용한다. 영구 성장이나 별도 재화는 첫 확장에 넣지 않는다.

| 보상 | 효과안 |
| --- | --- |
| 법인카드 | 탄약 보충 |
| 산재 처리 | 체력 회복과 최대 체력 증가 |
| 퇴근 본능 | 달리기 게이지 회복 강화 |

2차 적용 수치: 법인카드는 권총 200·샷건 100·로켓 20으로 보충한다. 산재 처리는 최대 체력 +20·현재 체력 +40, 최대 체력 상한 160이다. 퇴근 본능은 회복 속도 +25%를 합산하며 최대 +75%다. 세 보상 모두 층별 반복 선택이 가능하고 영구 저장하지 않는다. 선택 화면 중에는 전투를 진행하지 않는다.

## 엔딩

대표는 쓰러지면서 아래와 같은 대사 중 하나를 무작위로 말한다.

- “그래도 자네 월급은 동결이야.”
- “정규직 시켜주려고 했는데…”
- “내일은 정상 출근인 거 알지?”

주인공이 출입구의 퇴근 버튼을 누르면 “퇴근이 승인되었습니다.”가 나온다. 잠시 조용해진 뒤 휴대전화에 “월요일 오전 9시 긴급회의.”가 뜬다. 주인공은 휴대전화를 뒤집어 놓고 걸어 나간다.

구출한 동료가 있으면 함께 나가고 비서도 뒤따른다. 큰 분기 대신 짧은 장면 차이로 선택의 결과를 보여준다.

기존 확인 버튼은 첫 메뉴, 재게임은 1층부터 새로 시작하는 동작을 유지한다. 추가 버튼안은 “무한 파괴로 스트레스 더 풀기”다. 재게임 시 구출 여부·목표·선택 보상을 초기화한다.

## 화면과 대사 원칙

- 전투 자막은 화면 상단 한 줄로 짧게 표시하고 조준과 피격 상황을 가리지 않는다.
- 목표는 서버 아이콘 1/3, 동료 아이콘 0/1처럼 아이콘과 숫자로 전달한다.
- 긴 설명과 보상 선택은 안전한 엘리베이터 구간에 둔다.
- 도입과 보스 연출은 건너뛸 수 있게 하되 필수 상태 변경과 보상은 누락하지 않는다.
- 필수 대사는 해당 사건에서 한 번만 재생하고 반복 사망 시 빠르게 복귀한다.
- 성우 녹음 없이도 메시지, 방송 자막, 환경 표지로 이해할 수 있게 만든다.

완료된 항목만 체크한다. 구현과 실제 실행 검증 결과를 함께 기록한다.

### 1차 동기와 목표 검증

- [x] 두 선택지 앞에 공통 프롤로그 추가
- [x] 출근 엔딩에서 파괴 경로로 재도전 연결
- [x] 2층 서버 3개 목표와 동료 구출 추가
- [x] 파괴 순서와 구출 여부에 관계없이 진행 가능한지 확인

완료 기준: 처음 보는 사람이 파괴하기만 선택해도 주인공이 화난 이유와 3층으로 가는 이유를 이해한다. 서버 파괴가 실제 전투 상황을 바꾼다.

### 2차 층별 진행 연결

- [x] 1층 퇴근 거부와 단말기 목표 추가
- [x] 목표 및 지정 전투 기준으로 층별 이동 조건 변경
- [x] 엘리베이터 보상 3종 추가
- [x] 목표 상태, 보상과 구출 결과의 층 이동 및 재게임 처리

완료 기준: 남은 일반 적을 찾느라 진행이 멈추지 않고, 필수 목표를 건너뛰어 다음 층으로 이동하지 않는다.

### 3차 임원 전투 차별화

- [x] 임원 3종 패턴과 공격 예고 구현
- [x] 책임 회피 대사와 결재 문서 연결
- [x] 대표실 접근 권한 획득 연출

완료 기준: 세 전투의 공략 차이가 보이고 보호막 해제나 공격 예고를 자막 없이도 파악할 수 있다.

### 4차 대표전과 퇴근 결말

## 문서 유지 방법

스토리 확장 작업을 시작할 때 이 기획서와 관련 코드를 함께 확인한다. 사용자의 새 요청이 기획과 달라지면 해당 항목과 아래 변경 기록을 먼저 갱신한다. 구현이 끝난 항목만 체크하고, Editor 확인과 Web 확인은 구분해서 기록한다.

### 1차 적용 세부 사항

- 프롤로그는 36초간 사무실 그림, 시간 표시, 메시지와 출입 안내로 진행하며 건너뛰기를 제공한다.
- 2층 기존 직원 중 3명을 주황색 이름표의 방어 담당으로 지정한다. 일반 직원과 증원 처치는 필수가 아니다.
- 업무 서버는 9초마다 증원하며 살아 있는 증원은 최대 2명, 보고서 서버는 3초마다 서류 3장을 발사한다.
- 근태 서버 파괴 후 동료 3m 이내에서 E로 구출한다. 보상은 3층 입구 회복 보급과 대표전 체력 70 이하에서 1회 +30이다.
- 기존 프리팹과 이후 층·대표전은 보존한다. 신규 2층 목표물은 SetupStoryFloor()에서 추가하며 시각 편집용 프리팹 반영은 이번 범위에 포함하지 않았다.
- 1차 완료 당시에는 로비 단말기, 임원 패턴, 엘리베이터 보상, 새 퇴근 엔딩이 미구현이었다. 로비와 엘리베이터는 아래 2차 변경을 따른다.


### 2026년 11월 24일 1차 검증 결과

격리된 Unity 6000.5.1f1 프로젝트에서 컴파일과 Play 검사를 통과했다. 이동·점프·바닥·벽 충돌, 프롤로그 시간과 선택, 실제 출근 사망 연출과 직접 재도전, 서버 파괴 순서 6가지, 방어 담당 선처치와 서버 선파괴, 구출 여부, 증원 상한 및 중단, 서류 공격 생성, 일반 적이 남은 상태의 출구 개방, 일회성 보상과 새 게임 초기화, 일시정지, 무한 모드 격리를 확인했다.

프롤로그와 2층 목표 HUD의 화면 캡처를 확인했다. Web 빌드와 브라우저 실행, 사람이 직접 수행하는 전체 플레이의 난이도 평가는 미확인이다. Unity Editor 검색 인덱스에서 기존 SearchDatabase 예외가 한 번 발생했으며, 게임 코드의 검사 오류와는 구분했다.


### 2026년 11월 25일 2차 적용

- 로비에서 E로 퇴근을 요청하면 거절과 이상자 등록 안내 후 전투가 시작된다. 단말기 선공격이나 보안 대응 인원 선처치도 전투를 시작시키므로 순서에 따른 막힘이 없다.
- 1층은 단말기와 보안 대응 3명, 2층은 기존 서버 3개와 방어 담당 3명, 2차 당시 3층은 기존 임원 6명을 필수 대상으로 등록했다. 3차에서는 아래처럼 지원 인원까지 포함한 세 전투 완료 조건으로 변경했다.
- 엘리베이터가 닫힌 안전 구간에서 보상 1개를 선택한다. 각 이동 구간은 한 번만 지급하며 일시정지·메뉴 복귀·새 게임을 처리한다.
- 최대 체력 보상은 HUD, 포션, 정수기와 동료 지원에 반영한다. 달리기 보상은 회복에만 적용하고 10초 지속시간은 유지한다.
- 동료 구출, 수령한 보상은 층 이동 시 유지하고 새 게임에는 초기화한다.
- 2차 완료 당시 임원 수행원·비서, 임원 패턴, 결재 권한과 새 엔딩은 후속 작업이었다. 임원 관련 항목은 아래 3차 적용을 따른다.

검증: 격리 Unity 6000.5.1f1에서 컴파일·Play 검사 통과. 이동·점프·바닥·벽 충돌, 로비 단말기/보안 대응 양쪽 처리 순서, 일반 적 잔존 상태의 진행, 실제 엘리베이터 1→2→3→4층 이동, 보상 중 전투 정지·중복 방지·일시정지 복귀 시 커서, 최대 체력과 회복·달리기 효과·일반 탄약 보충, 구출 유지, 메뉴 복귀 취소·새 게임 초기화·무한 모드 격리를 확인했다. 보상 선택 화면 캡처의 한글과 버튼 배치도 확인했다. Web 빌드 및 브라우저 실행은 미확인이다.


### 2026년 11월 25일 3차 임원 전투 적용

- 기존 임원 6명에 운전기사 겸 수행원 6명, 수행 비서 3명, 결재 담당 3명을 추가했다. 세 차례에 걸쳐 임원 2명과 지원 4명씩 등장한다.
- 결재 장치 대신 결재 담당이 보호막을 제공한다. 담당자가 살아 있는 동안 같은 전투의 임원 피해를 차단하고, 담당자 처치 즉시 해제한다.
- 첫 임원 쌍은 체력 180과 7장·70도 종이 다발, 두 번째는 체력 220과 반경 8m 확장 음파·공격 후 1.4초 틈, 세 번째는 체력 260과 음파/종이 교대 패턴이다.
- 운전기사는 근접 밀치기, 비서와 결재 담당은 5장·60도 종이 다발을 사용한다. 종이는 0.9초 예고, 원형 음파는 1.1초 예고 후 공격한다.
- 세 전투 모두 지원 인원까지 처치해야 완료하며, 전투 사이에는 2초 간격을 둔다. 숨겨진 다음 인원은 피해·빙결·기절에서 제외한다.
- 임원 패배 시 책임 전가 대사를 표시하고, 마지막 전투를 완료하면 주말 수당·임원 골프 결의서와 대표실 결재 권한을 알린다. 권한은 이번 플레이 상태이며 새 게임에 초기화한다.
- 대표층의 비서와 보스 전투, 다른 층과 무한 모드의 종이 공격은 유지한다. 기존 임원의 이름·성별은 설정을 따르고 추가 지원 역할은 고정 이름을 사용한다.
